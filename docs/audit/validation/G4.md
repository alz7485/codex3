- 実行ID: attendsync-audit-framework-smoke / 監査対象: `/workspace/codex3` の監査設定と helper のみ。

- 基準: この実行時の現行ファイルをSHA256で固定。親指示に従いgit操作なし。

## 結果

確定不具合なし（今回の設定・CLI入力範囲）。`check` は exit 0、product_audit_executed=false。normal/complete 各 capacity=1,2,3,4,5,6,7,99 の16計画で、全12役の重複/漏れなし (`scripts/audit_control.py:78-86`)、各waveが min(要求,6,設定6) 以下、最終巡以外は上限まで充填 (`scripts/audit_control.py:76-88`)。capacity=2 は normal=[2,2,2] / complete=[2,2,2,2,2,2]、既定相当6は complete=[6,6]。capacity=0,-1 の4計画は exit 2 で正しく拒否。

計画は並列実施可能なジョブをwaveへ編成するだけ。実際の起動・稼働時上限を実証したものではない。統括は coordinator_after_all_reports として別途指定され専門waveへ混在しない。

## 起動/実監査の偽装確認

`scripts/audit_control.py:1` は説明で「does not launch agents or tests」、check は product_audit_executed=false (`:66`)、plan は spawn_agents=false / modify_product=false (`:94`)。全ソースの静的読取でload/check/planは設定の読込とJSON編成、mainはstdout/stderr出力のみ。resolveは候補の読取/指紋案内だけ（今回未実行）。importは標準ライブラリのみ。外部通信、認証、メール、spawn、製品テスト起動処理はない。製品の性能・省力化監査は実施していない。
