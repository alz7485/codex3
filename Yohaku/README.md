操作は次のとおりです。

- キャラを**ドラッグ** → 好きな位置へ移動します。移動後の位置は自動保存し、次回起動時にも使います。別モニターへも移動できます。
- 短時間の**連打** → 困る・少し怒る表情とセリフで返します。本文をクリックして閉じるまで左クリックの追加発言・カウントを停止します。
- キャラを**左クリック** → 状況に合う一言の本文だけを吹き出しに表示します。ドラッグでは発言しません。通常メッセージは×なし・本文に合う高さで、メッセージをクリックして閉じます。
- キャラ・吹き出しを**右クリック** → 「お呼びですか？」等の下に「予定を聞く」「ファイル起動履歴を見る」「設定を開く」「通知を設定する」「非表示にする」の5行を表示します。
- メニューからメッセージの選択肢はなくしました。メッセージは左クリックで聞きます。呼び出し中の再右クリックは吹き出しを閉じ、呼び出しの本文・余白をクリックすると、キャラを残してメッセージだけを閉じます。予定と今日の履歴は同じ吹き出しで表示し、履歴の詳しい操作は「管理画面を開く」から進みます。設定は専用画面です。
- 「非表示にする」でキャラと吹き出しを隠します。通知領域のアイコンを左クリックすると表示／非表示を切り替えます。アイコンの右クリックで設定・終了などを選べます。
- アニメーション・歩行・PC状態の集計・新着通知は設定から切り替えます。ファイル起動履歴は引き続き初期設定オフです。

採用キャラは **つづり（ノート） / ビット（ロボット） / ペギー（ペンギン） / きなこ（お茶ねこ）** です。「キャラと通知」の先頭にあるサムネイルをクリックすると、常駐キャラ・操作画面・トレイアイコンが即時に切り替わります。選択は自動保存され、次回起動時にも引き継ぎます。初期設定はつづりです。性格は「キャラクターに合わせる」が初期値で、つづり＝気の利く皮肉屋、ビット＝几帳面な分析役、ペギー＝まじめな応援係、きなこ＝お茶好きののんびりした同僚です。設定で7種の性格から自由に選べます。追加の「馴れ馴れしい関西弁」「寡黙な先輩」「孤高の債務者」も、4キャラのどれにも組み合わせられます。

見た目の切り替えではOutlookの接続状態・取得中の処理・表示中の通知・おやすみ・画面共有モード・重複通知の履歴を変更しません。旧版の設定も読み込めます。旧版から初めて更新した際は会話の間隔を10分へ移行し、その後は選んだ間隔を保持します。既存の性格の個別指定は保持します。「キャラクターに合わせる」で4キャラ固有の性格を使えます。キャラの指定がない、または不正な場合はAを使用します。

会社のデスクトップで目立ちすぎない小さなキャラクターです。AI API、音声、効果音、広告、利用状況の送信、自動アップデートはありません。キーの内容・クリック位置・入力文は記録しません。PC状態の集計ではWindowsの最終操作時刻から経過秒数を取得し、操作あり／なしの時間を推定します。アプリ自身に外部送信用のクライアントはありません。Outlook自体の同期動作はOutlookの設定に従います。

## Windowsで起動する

対象は **Windows 11 / Python 3.11 または3.12 / 従来版Outlook** です。これはソースコードのZIPです。Windows用EXEは含んでいません。

1. 2つのZIPを両方ダウンロードし、ユーザーが書き込める同じ場所へ展開します。両方の `Yohaku` フォルダーを統合し、共通ファイルの上書きは許可します。片方だけでは起動・ビルドに必要なファイルが揃いません。
2. Python 3.11または3.12が導入済みの環境で、下の直接コマンドで起動します。初回はPySide6とpywin32を導入します。管理者権限は不要です。
3. 初回は右下、移動済みの場合は保存位置にキャラクター、タスクバーの通知領域にアイコンが現れます。キャラを右クリックして「設定を開く」を選んでください。接続前でも「通知を試す」で見た目を確認できます。このボタンは静かな時間・おやすみ設定にかかわらずプレビューを表示します。画面共有モード・キャラ非表示中は表示しません。
4. **従来版Outlookを起動してから**「Outlookに接続」を押します。最初の接続後は、次回起動から自動で再接続します。切断はトレイメニューから行います。
5. 操作画面を閉じても常駐します。キャラを右クリック→「非表示にする」でキャラと吹き出しを隠します。通知領域のアイコンを左クリックするとキャラの表示／非表示を切り替えます。終了は通知領域のアイコンを右クリックして「Yohakuを終了」です。
6. 左クリックで一言、右クリックで呼び出しと5行の選択肢が出ます。設定画面・履歴ウィンドウ・吹き出し・通知を閉じると、しばらくして現在の高さを水平に歩き始めます。初期設定の静かな時間（18:00〜翌09:00）は動きません。動作を試す場合は、静かな時間の開始と終了を同じ時刻にしてください。

会社の端末では、Python実行・依存パッケージ導入・Outlook COM利用について、その会社の通常の導入ルールを適用してください。制限を迂回する機能はありません。

手動で起動する場合：

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

導入時のダウンロードが認められていない環境では、管理担当者が用意した適合するwheel群から `pip install --no-index --find-links <wheelフォルダー> -r requirements.txt` で導入できます。実行時のAI用キー・外部サービスの認証は不要です。

## 小さなMVPの動作

- 初回はプライマリ画面の右下から開始します。キャラを押したままドラッグすると、別モニターを含めて好きな場所へ移動できます。手を離した位置を保存し、次回起動時もその位置から開始します。自動歩行は置いた高さの水平移動です。初回は2〜4秒程度待ち、その後は2〜5秒ほどの小休止を挟んで24〜56pxを毎秒20px程度で移動し、画面端で折り返します。キャラのウィンドウ下端を作業領域の下端まで下げられ、足元がタスクバーの直上に来ます。従来の12pxの下余白と常駐キャラの3pxの描画余白をなくしました。画面の抜き差しや保存位置が画面外の場合は利用可能な画面内へ補正します。ドラッグ中は歩行・表情更新を止め、発言を起こしません。
- 各キャラ8コマの歩行と20種の表情・しぐさを使い、約60fpsを目安に描画します。歩行8コマの接地位置と中心をそろえ、移動は滑らかに加減速し、呼吸・体の揺れ・サブピクセル移動・透明度を保った短いコマ補間を加えます。歩行中は進行方向を向き、待機の基本姿勢は正面です。ウィンドウの移動直後に描画します。Fは湯のみごと移動します。待機中のしぐさは初回約5秒、その後5〜9秒ごとに考え中・首かしげ・うなずき等の候補を選び、既存の反応を優先します。会話の話題と連動した表情に変わり、冒頭では短い口パクも行います。静かな時間・おやすみ・画面共有モード・非表示中はアニメーションを停止します。設定画面・吹き出し・通知の表示中、キャラ上でポインターを動かしてから約2秒間は歩行を止めます。ポインターが止まったままなら短い間を置いて再開し、押している間・ドラッグ中は止まり続けます。
- 普段の会話・予定・受信通知・呼び出しに同じ幅322pxのしっぽ付き吹き出しを使います。白＝一言、淡い黄＝予定、淡い青＝新着、薄緑＝呼び出し。通常の一言は見出しと選択肢を付けず本文だけを表示し、右クリックで5行の呼び出しを出します。上部に空きがないときはキャラの下へ吹き出しを出し、しっぽも上向きになります。通常メッセージは初期20秒、通知は1分。通常メッセージには×を付けず、本文の行数に合わせた高さとし、クリックで閉じます。すべての吹き出しで見出しと×を省きます。Escでも閉じます。予定は最新結果から当日10件まで表示し、長い場合はスクロールできます。
- 履歴の専用ウィンドウはカレンダー＋ファイル一覧で、その日ごとに2,000件まで表示します。ファイル名欄は340pxを確保し、取得元の列をなくしました。行をダブルクリックすると既定のアプリでファイルを開きます。選択日は青、今日は黄で表示し、今日が選択中なら青に黄の枠を重ねます。メッセージ・予定を選んでも、開いている履歴ウィンドウはそのまま残ります。閉じても常駐アプリは終了しません。雑談の自動発言は吹き出し操作を待ちますが、予定開始前の通知は優先して表示します。
- 従来版Outlookの既定予定表と既定受信トレイの会議案内から、当日と今週（月曜〜日曜）の時間指定の予定を2分ごとに読み取ります。未承諾・仮承諾も表示し、共通のGlobalAppointmentIDを取得できる同じ会議は重複させません。承諾・辞退・既読化・予定追加は行いません。読み取りは別スレッドです。一部の取得失敗では取得済みの予定を残し、画面に一部取得の状態と理由を表示します。
- 開始10分前から開始直前までに取得できた予定を、1つの開催回につき1回知らせます。アプリ停止中の予定通知は行えません。通知を見送ったまま開始時刻を過ぎた場合は後追いしません。
- 繰り返し予定は開催日時を含むキーで区別します。終日予定、キャンセル済みの予定は対象外です。今日より前に開始した複数日予定もMVPの通知対象外です。
- 接続失敗時は予定通知を止め、キャラクターと雑談を利用できます。前回取得から5分以上経った予定データでは通知しません。
- 雑談は初期設定で約10分ごと（15秒単位で判定）。編集画面で1〜1,440分に変更できます。起動直後の挨拶、朝・昼・午後・夕方、月曜・金曜・週末、予定の前後、起動から1時間以上、気分転換・目・姿勢・飲み物・応援・キャラ雑談などの話題から選びます。話題は編集画面から追加できます。予定通知を優先し、最新の予定データで会議中なら雑談を控えます。設定・履歴・会話編集・吹き出しを操作中も自動会話を待ちます。操作内容の監視や実際の在席・労働時間の判定は行いません。
- 7種の性格それぞれに各217、計1,519のセリフを収録（操作時の案内を含む）。未使用・最後に話してから時間が経った話題を優先し、同じ話題は基本1時間空けます。セリフも話題ごとに直近最大12個を避けます。手動で続けて聞いた場合は話題を切り替えて返します。会話の編集画面から、セリフ・発生条件・重み・表情・再発言間隔・キャラ説明を編集できます。会話はすべてローカルの定型文です。
- 静かな時間は初期設定で毎日18:00〜翌09:00。予定通知も雑談も停止します。同じ開始・終了時刻を設定すると時間帯指定を解除します。
- 「1時間おやすみ」は予定通知も雑談も停止します。途中解除が可能です。再起動で解除されます。
- 「画面共有モード」はキャラ・吹き出し・操作画面・履歴ウィンドウを隠して自動発言を停止します。トレイから解除できます。画面共有を自動検知する機能ではありません。トレイから操作画面を明示的に開くことはできます。トレイを使えない環境ではこのボタンを無効にします。
- 通常の雑談・クリック後の一言・呼び出しは初期20秒、メール・予定開始前・単発・退勤前などの通知は1分で閉じます。通常メッセージだけ会話編集で5〜300秒に変更できます。自動表示ではフォーカスを奪いません。非表示中は自動会話・通知を止め、表示に戻しても過去の雑談をまとめて出しません。トレイが使えない環境では非表示を行わず設定画面を出して、復帰できない状態を防ぎます。
- 同一ユーザーでの二重起動をロックファイルで防ぎます。Windowsのスタートアップへの登録は行いません。

初期状態では予定件名を取得・表示しません。明示的に件名表示をオンにした場合のみ件名も読み取り、画面と通知に表示します。オフに戻すと表示・キャッシュを直ちにクリアし、進行中の古い取得結果も破棄します。出席者、本文、添付ファイルは読み取りません。

## 自分で登録する通知

「キャラと通知」→「自分で登録する通知」→「通知を登録・編集」で、条件・時刻・メッセージを登録します。「月末の最終平日」「毎月○日までの最終平日」「毎日」「毎週・曜日指定」「毎月・日付指定」に対応し、次回の対象日を画面で確認できます。例えば2026年10月末は10月30日（金）、2026年11月の15日締めは11月13日（金）です。

初期は登録0件、100件まで登録可能。平日は月〜金で、祝日・会社独自の休日は除外しません。通知は指定時刻から10分以内に1回、メッセージだけを青い吹き出しで表示。再起動による重複を防ぎ、同時刻の登録は既存の吹き出しが閉じてから1件ずつ表示します。非表示等では抑制され、期限を過ぎた通知は後追いしません。条件もメッセージもJSONで保存します。[登録方法とJSONの仕様](docs/REGISTERED_NOTIFICATIONS.md)を参照してください。

## 退勤前のお知らせ

「キャラと通知」→「退勤前のお知らせ」で、有効・平日だけ・時刻・メッセージ・勤怠サイトのURLを入力し、「退勤前通知の設定を保存」を押します。初期は無効、時刻は **17:00**、平日（月〜金）です。URLは利用者が入力します。

指定時刻から10分以内に1日1回、退勤前の吹き出しを出します。Windowsの起動時刻と起動後の経過時間を添え、「勤怠サイトを開く／あとで」を選べます。URLが未登録なら「URLを設定する」で設定画面へ案内します。サイトは選択したときだけ既定ブラウザーで開き、自動入力・送信は行いません。http/httpsだけを受け付けます。

非表示・共有・おやすみ・静かな時間中は出さず、10分以上過ぎた通知は後追いしません。アプリ停止中の通知は行えません。同じ日に再起動しても通知済みの日付を確認します。起動時刻はWindowsのGetTickCount64から求めた目安で、スリープ等を含みます。高速スタートアップでは前回のカーネル起動から続く場合があります。実際の勤務時間の集計ではありません。

## 会話を編集する

「キャラと通知」→ **「会話文・発生ルールを編集」**、または通知領域のアイコンを右クリック→「会話を編集」で開きます。

1. **会話文**：性格と話題を選び、セリフを追加・変更・削除します。改行も使えます。
2. **発生ルール**：話題の有効・無効、条件（時間帯・曜日・起動からの経過・予定前後・PCやファイルの集計値・AND/OR）、出現しやすさ、少し優先する度合い、同じ話題の間隔、表情を編集します。独自の話題も追加できます。
3. **全体設定・性格**：会話間隔、吹き出しの表示秒数、予定通知の何分前、会議中の抑制、重複回避、キャラの性格・説明・代表的な一言、始業・終業（初期8:30〜17:30）を編集します。
4. **保存して反映**：検証後に `%LOCALAPPDATA%\Yohaku\dialogue.json` へ保存し、動作中の会話へ反映します。保存前の編集は動作に影響しません。

「JSONを読み込む／書き出す」でほかのPCへ移せます。「初期値へ戻す」は編集状態を初期値へ戻し、「保存して反映」で確定します。変更を取り消す操作も用意しています。不正なJSONや保存失敗時は現在の会話を変更しません。起動時に保存済みJSONが壊れていた場合は初期値で動作し、元のファイルを保持して編集画面に理由を表示します。

初期データは `companion/assets/dialogue/default_dialogue.json`。会話の内容・条件をPythonコードに直接書き込む必要はありません。詳しい形式は [DIALOGUE_JSON.md](docs/DIALOGUE_JSON.md) を参照してください。

## PCの状態に応じた会話と即時通知

勤務時間は初期 **8:30〜17:30**。JSON編集の「全体設定・性格」で変更できます。新しい条件は「発生ルール」の「PC・ファイル・予定の集計値」から選び、下限・上限を設定します。AND/ORでは複数条件をJSON配列で組み合わせます。

- 操作が何分ないか、操作あり推定時間が何分続いたか、今日の操作あり／なしの累計。
- 取得できるExcel・Word・PowerPointの文書数が多い／少ない、デスクトップのファイル数が多い／少ない。
- 始業・定時まであと何分、定時を何分過ぎたか。
- 今日同じファイルを何度も開いたか（ファイル履歴オン時だけ）。
- 昨日このアプリを使った記録がないか、前回使用日から何日空いたか。
- 今週・今日の時間指定の予定が多い／少ない、次の予定まであと何分か。

PC状態の集計は初期オンで、設定からオフにできます。最後の操作から60秒以内を「操作あり」とする初期設定で、5秒ごとに推定します。アプリ停止中・スリープ中の時間は足しません。日別集計は35日保持し、設定から削除できます。これは実際の作業・在席・労働時間の記録ではありません。Office文書数とデスクトップ件数は約1分ごとに確認し、名前や内容を集計ファイルへ保存しません。アプリ自身の使用日はPC状態の集計をオフにしても記録します。

新着通知は「Outlookに接続」後に開始します。NewMailExイベントで即時に、受信トレイでも1秒ごとに検知します。「メールが届きました。」だけを通知し、送信者名・新着件数は表示しません。送信者名・アドレス・件名・本文・添付ファイルを読みません。送信者を表示する設定は削除し、旧設定がオンでも無効にします。最初の受信は即表示し、直前の受信から3秒以内の連続受信は同じ通知の表示時間を延ばします。閉じた直後の同一連続受信では再表示しません。イベントと確認の重複、仕分けでEntryIDが変わった同一メールの重複を除外します。

受信トレイの未読数は `UnReadItemCount` から取得します。未読5件以上で「未読メールが{unread_mail_count}件たまっています」等の通常会話を候補にし、重み2・優先度1で少し選ばれやすくします。通知色は使わず、普段の白い吹き出しです。約10分の会話間隔と1時間の同一話題の間隔を守り、未読数が変わるだけで即時表示しません。しきい値・優先度・間隔・セリフは編集UIで変更できます。90秒以上古い値や取得不能な値では発言しません。既定の受信トレイが対象で、全アカウント・全フォルダーの合計ではありません。

新着通知は10分の会話間隔や設定・呼び出し操作を待ちません。非表示・画面共有・おやすみ・静かな時間中は表示せず、後からまとめて出しません。Teams等の他アプリや新しいOutlookの通知は対象外です。取得できない・古い情報は条件から外します。範囲と初期しきい値は [CONTEXT_NOTIFICATIONS.md](docs/CONTEXT_NOTIFICATIONS.md) に記載しています。

### ファイル履歴の範囲と日付選択

キャラの吹き出しで「ファイル起動履歴を見る」を選ぶと専用ウィンドウが開きます。左側のカレンダーから過去3か月の日付を選択し、「今日に戻る」で当日へ戻れます。その日の記録を最大2,000件、ファイル名・完全な保存先・時刻の3列で表示します。ダブルクリックで既定のアプリから開きます。長い保存先は行にポインターを置くと全文を確認できます。記録のない日は「この日の記録はありません」と表示します。同名でも保存先が違うファイルは別々に記録します。記録オフのままでも保存済み履歴の日付を選んで閲覧できます。

取得元は、既に起動しているExcel・Word・PowerPointの文書一覧と、Windowsの「最近使ったファイル」のショートカットです。Officeを起動したり、文書を開いたり、本文を読んだりはしません。取得できるOfficeインスタンスのみ対象で、複数インスタンスの全件取得は保証しません。最初に取得できた開いているファイルと既存の最近使ったファイルを基準にし、その後の変化を記録します。オンにする前の履歴を遡って取り込む機能はありません。

5秒間隔なので短時間の開閉は見逃す場合があります。Officeが応答しないとき、Windowsが履歴を残さないソフト、最近使ったファイルの記録が無効な環境、ブラウザー内の文書、未保存の文書等は記録できない場合があります。これは網羅的なファイル操作監査ではありません。Officeは新しく一覧に現れたファイル、Windowsは最近使ったファイルの更新を検出するため、表示する時刻は初回確認またはショートカット更新の時刻です。保存先の変更も別ファイルとして記録される場合があります。同じファイルの複数取得元からの通知や15秒以内の再検出は1件にまとめます。開き直しは閉じた状態と再表示を確認できた場合に記録します。

**ファイル名と完全な保存先を保存します。** 文書の内容、キーボード入力、起動コマンド、予定件名は履歴に保存しません。ショートカットの参照先の文書・ネットワークパスを読み込んで確認する処理も行いません。ファイルを開いたり、移動・削除したりする機能はありません。

オフにすると新しい確認と記録を停止します。保存済み履歴は閲覧・削除できます。履歴削除は進行中の古い確認結果も破棄し、記録オンなら新しい基準から再開します。期限切れは起動後の定期処理、1時間ごとの整理、履歴の読み書き時に削除します。アプリ終了中の期限切れは次回起動時に整理します。画面共有モード中も、記録がオンなら記録は継続します。

## Windows用配布フォルダーを作る

Windows 11 / 64bit Python 3.11または3.12で、展開した`Yohaku`フォルダーをターミナルで開き、同梱の **`ONEDIR_COMMAND.txt`** のコマンドを順に貼り付けて実行します。バッチ・PowerShellスクリプト・仮想環境の有効化は使いません。

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm --clean Yohaku.spec
.\.venv\Scripts\python.exe scripts\collect_licenses.py dist\Yohaku
.\.venv\Scripts\python.exe -c "import shutil; shutil.make_archive('Yohaku-v0.20.0-windows-x64-onedir', 'zip', 'dist', 'Yohaku')"
```

Python 3.12の場合は、1行目を `py -3.12 -m venv .venv` に変更します。

3行目がonedirを作るコマンドです。`Yohaku.spec`にフォルダー形式、アイコン、4キャラとアニメーション素材、製品名・版を定義しています。出力は `dist\Yohaku\Yohaku.exe`。5行目で作るZIPは作業フォルダー直下の `Yohaku-v0.20.0-windows-x64-onedir.zip` です。

| 同梱ファイル | 用途 |
|---|---|
| `ONEDIR_COMMAND.txt` | ターミナルへ貼り付ける直接コマンド |
| `BuildWindows.cmd` | バッチが利用できる環境向けの補助入口 |
| `scripts/build_onedir.py` | 仮想環境の準備、PyInstaller、素材の確認、配布ZIPの作成 |
| `Yohaku.spec` | onedir用の定義。4キャラ・アニメーション・アプリアイコンを同梱 |
| `packaging/windows_version_info.txt` | Yohakuの製品名とバージョン情報 |
| `scripts/package_source.py` | 2つの独立したソースZIPとSHA-256の作成。ファイルを途中で切らず圧縮後の容量を均等化。ローカルの設定・履歴を除外 |
| `.github/workflows/yohaku-windows.yml` | GitHub ActionsのWindowsビルド定義 |

依存の導入から配布ZIPまでPythonのビルドヘルパーに任せる場合は、次のコマンドも使えます：

```powershell
py -3.11 scripts/build_onedir.py
```

ビルドヘルパーの場合の出力は `dist\Yohaku\Yohaku.exe` と `release\Yohaku-v0.20.0-windows-x64-onedir.zip` です。**EXEだけを取り出さず、ZIPをすべて展開して実行してください。** DLL・Qt・画像は同じフォルダーの`_internal`に入ります。配布物には依存ソフトウェアのライセンス文書もコピーします。署名・社内パッケージ化は含みません。LinuxからWindows EXEを作ったものではありません。

ビルド素材の確認だけなら `python scripts/build_onedir.py --check`、ビルド環境の準備だけなら `py -3.11 scripts/build_onedir.py --setup-only` を使います。Windows用ビルドはWindows上で実行してください。

### GitHubからダウンロードする

- ソースZIP：上のダウンロードリンク、または `downloads/Yohaku/` の案内から取得します。
- コード：`Yohaku/` に同じ完全ソースを置いています。
- GitHub Actions：リポジトリの「Actions」→「Build Yohaku Windows onedir」→「Run workflow」でWindowsビルドを実行できます。成功後の「Artifacts」からonedir ZIPとソースZIPを取得します。
- このプロジェクトを別のリポジトリに置く場合は、同梱の`.github/workflows/yohaku-windows.yml`を**リポジトリ直下**の同じパスに置いてください。ワークフローはリポジトリ直下、または`Yohaku/`にあるソースを検出します。

## 連打の反応を読む

困る・怒る反応の表示中はキャラの左クリックを受け付けず、回数も増やしません。本文または余白のクリックで吹き出しを閉じると再開します。反応の本文と表情は自動消去しません。通常の一言・予定の照会は初期20秒、通知は1分です。

右クリックは使え、呼び出しには未確認の反応も添えて残します。再右クリックは呼び出しだけを隠し、左クリックの停止は維持します。呼び出しの本文クリックまたはEscで明示的に閉じても停止を解除できます。「非表示にする」は従来どおりキャラごと隠します。

新着メール等は即時表示し、その通知を閉じると未確認の反応へ戻ります。自動会話が未確認の反応を追い越すことはありません。セリフ・しきい値は従来どおり会話JSONと編集UIから変更できます。10秒のリセット設定は次の受け付けたクリックの判定に使い、未確認メッセージの自動消去には使いません。

## プリセット・プレビュー・検索

「キャラと通知」の上部で「標準・控えめ・通知だけ」を選べます。標準は自動会話10分・歩行あり、控えめは30分・歩行なし、通知だけは自動雑談とアニメーションを停止します。通知だけでも手動の一言は使えます。個別に会話頻度・歩行・表情を変えるとカスタムになります。Outlook接続、ファイル記録、PC集計、静かな時間や退勤通知はプリセットで変更しません。保存に失敗した場合は元の設定を保持します。

「表情・通知のプレビュー」は、通常・困る・怒る・新着・予定・呼び出しの表示例を試す独立した画面です。本番の受信や連打、履歴の記録は不要で、通知済み状態や会話履歴にも影響しません。閉じるとプレビューの描画タイマーを停止します。

ドラッグで下端の初期16px以内に置くと、タスクバー直上へ足元をそろえて保存します。吸着はオフにでき、距離は4〜48pxで設定できます。歩行は約0.18秒の向き確認、約0.14秒の前傾、加減速する歩行、約0.22秒の停止姿勢を経て正面に戻ります。

履歴の検索欄に入力すると、選択日にかかわらず保存済みの全履歴（過去3か月・最大15,000件）のファイル名と保存先を部分一致で検索します。検索中は日時も表示し、日別表示の2,000件の上限は適用しません。大文字・小文字の違いを区別せず、%や_や引用符も文字として検索します。検索を消すと選択日の表示へ戻り、結果はダブルクリックで開けます。検索語は保存しません。期限切れ・削除済み・上限で削除した履歴は検索対象に戻りません。

同じ段階の困る・怒る反応は、前回の発生から初期30秒間は繰り返しません。困るから怒るへの変化は別に判定します。短い連打の回数がリセットされても、この間隔は保持します。秒数は会話編集の「同じ段階の反応を繰り返すまで」で変更できます。未確認の反応は従来どおり、閉じるまで左クリックを停止します。
