# デザイン仕様

「余白」は、机の隅に置ける控えめな存在感を目指したデザインです。現行版では普段の吹き出しに問いかけを出し、その下に4つの選択肢を1行ずつ並べます。「予定を聞く」左クリックの一言は吹き出し内で返し、履歴と設定はそれぞれの専用ウィンドウを開きます。

| ID | キャラクター | 雰囲気 |
|---|---|---|
| A | 余白ノート | 生成りのノート。自然になじむ文具風 |
| B | 事務ロボ | 青い目の小型ロボ。落ち着いた道具らしさ |
| E | まじめなペンギン | ネクタイ姿。端正できっちり |
| F | お茶ねこ | 湯のみに入った猫。水彩調で和やか |

設定ページの先頭にサムネイルを並べ、選択中のキャラに緑色の枠と背景を付けます。キーボードでも選択できます。初期設定はキャラ固有の性格です。Aは気の利く皮肉屋、Bは几帳面な分析役、Eはまじめな応援係、Fはのんびりしたお茶好き。設定で別の性格へ上書きできます。

| 要素 | 仕様 |

予定の件名は初期状態で隠します。件名を隠しても、通知の存在や時刻は周囲から見えるため、画面共有の前には画面共有モードを手動でオンにする設計です。開始前の通知には、拒否感の出やすい強い色やアラームを使いません。

皮肉は軽いユーモアにとどめます。職務能力・勤務態度を責める言葉や、他の参加者に向けた批判は使いません。「仕事をしているふり」「結局何か決まった？」などの強い発言は、この試作品では採用していません。

性格と頻度は設定ページへまとめ、普段の画面では接続状態・おやすみ・画面共有を優先しています。設定は即時保存し、保存に失敗した場合はその場で知らせます。

外観の切り替えは常駐キャラ・操作画面の2か所のキャラ・トレイとウィンドウのアイコンへ反映します。ウィンドウの位置や大きさは変えず、表示中の予定通知を閉じたり、非表示中のキャラを再表示したりしません。

キャラはドラッグで別モニターを含む任意の位置へ移動でき、離した位置を保存します。クリックは離した時点で判定し、ドラッグでは発言しません。自動歩行は置いた高さの水平移動です。画面端・モニター切断時は利用可能な画面内に補正します。画面上部では吹き出しをキャラの下へ出し、しっぽを上向きにします。スリープ復帰直後に大きく飛ばないよう、1回の移動時間を制限しています。吹き出し・設定画面・通知の表示中やマウスがキャラに重なる間は立ち止まります。静かな時間・おやすみ・画面共有・非表示中はアニメーションも停止します。設定で表情アニメーションと歩行を変更できます。

吹き出し操作中は雑談を見合わせます。開始前の予定通知は優先します。ファイル履歴はユーザーが設定でオンにした場合だけ取得し、ファイル名と保存先を端末内に保存します。ファイル本文・入力内容は読みません。表示時刻は検出・最近使ったファイルの更新時刻の目安です。記録のない日付も選択でき、空の状態を表示します。

通常メッセージは本文だけを表示し、「○○から、ひとこと」等の見出しを付けません。呼び出し・予定・新着・退勤前通知も見出しと×を付けず、本文と必要な選択肢だけを表示します。クリック直後は通常の雑談と分けた問いかけを表示します。例は「お呼びですか？」「用事は何でしょう？」「何？」です。性格ごとの候補から直近の重複を避けて選びます。履歴や設定を選ぶと吹き出しは短い案内だけを返し、対象の画面を開きます。履歴の閉じる操作でアプリは終了しません。画面共有モードでは履歴ウィンドウも隠します。

キーボードではTabで各操作へ移動でき、ボタンにフォーカス枠を表示します。吹き出しは本文のクリック・Esc・時間経過で閉じます。高コントラストモードとスクリーンリーダーの実機評価は未実施です。

通知領域に常駐します。アイコンの左クリックでキャラを表示／非表示。右クリックのメニューから設定・おやすみ・共有・終了を行います。キャラ・吹き出しの右クリックは呼び出しを出し、「非表示にする」で隠します。復帰時に古い吹き出しは戻しません。会話ルールの詳細は[CONVERSATION.md](CONVERSATION.md)を参照してください。

会話編集は専用の通常ウィンドウです。「会話文」「発生ルール」「全体設定・性格」の3タブで編集します。条件の種類に合う入力欄だけを表示します。保存前は動作へ反映せず、「保存して反映」で検証・JSONへの保存・即時反映を行います。保存失敗や不正データは画面内で説明し、編集中の内容と動作中のデータを保持します。

予定の吹き出しは淡い黄（#FFF3D4）、新着通知は淡い青（#E7F1FF）、会話は白、呼び出しは薄緑です。本文と色で区別します。受信通知はフォーカスを奪わず、検知後すぐ同じ吹き出しに表示します。

コマ補間では前後の画像を別々の透明面で重み付けしてから加算し、完成した1枚を描画します。二重のsource-overで重なる不透明部分が約75%へ薄くなるちらつきを防ぎます。歩行後も現在の向きを維持し、ネイティブウィンドウの移動直後に再描画します。同じ整数位置への再移動や、しっぽ位置が変わらない吹き出しの再描画は省きます。Windowsの合成描画・表示倍率ごとの実機評価は未実施です。

すべての吹き出しでヘッダー領域と×ボタンを削除し、本文の実際の折り返し・改行に合わせて高さを求めます。上下10pxの余白としっぽ12pxだけを足し、ウィンドウの最小100pxへの拡張を使いません。本文・余白の左クリックで吹き出しだけを閉じます。呼び出しの選択肢や右クリックは維持します。新着は送信者を表示し件数を付けず、未読の件数は白い通常会話へ分けます。

予定の一覧・次の予定・開始前通知には「未承諾」「仮承諾」の状態を添えます。予定表と受信トレイを統合し、取得できなかった部分は接続表示と吹き出しに明示します。部分取得時の予定件数は不明として会話に使います。

履歴ウィンドウは初期1180×620、最小1000×500。時刻・ファイル名・保存先の3列で、ファイル名は初期340pxです。ダブルクリックで既定アプリから開き、取得元は内部互換用に保持して画面には出しません。暦上3か月・15,000件、日別2,000件を上限にします。選択日は青（#1D4ED8）、今日は黄（#FDE68A）で、選択中の今日には黄の枠を付けます。

退勤前通知は初期無効・平日17:00。設定で時刻・文言・URLを保存し、1日1回、10分の有効時間内だけ表示します。薄い橙の吹き出しにWindows起動時刻と経過時間、「勤怠サイトを開く」「あとで」を出します。URL未登録なら設定へ案内します。クリックしたときだけブラウザーで開き、自動送信はしません。
