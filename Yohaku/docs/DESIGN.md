# デザイン仕様

「Yohaku」は、机の隅に置ける控えめな存在感を目指したデザインです。現行版では普段の吹き出しに問いかけを出し、その下に5つの選択肢を1行ずつ並べます。「予定を聞く」は呼び出しを閉じて予定本文を表示し、左クリックの一言も本文だけを表示します。履歴は今日のファイル名のリンクを吹き出しで表示し、末尾の「管理画面を開く」から専用画面へ進みます。設定は専用画面を開きます。

| ID | キャラクター | 雰囲気 |
|---|---|---|
| A | つづり | 生成りのノート。自然になじむ文具風 |
| B | ビット | 青い目の小型ロボ。落ち着いた道具らしさ |
| E | ペンギー | ネクタイ姿。端正できっちり |

設定ページの先頭に3体のサムネイルを並べ、選択中のキャラに緑色の枠と背景を付けます。キーボードでも選択できます。初期設定はキャラ固有の性格です。つづりは控えめな皮肉屋、ビットは冷静な案内役、ペンギーは元気な応援係。関西弁・寡黙な先輩・孤高のギャンブラーを含む全7性格を、どのキャラにも指定できます。

| 要素 | 仕様 |

| 常駐キャラ | 82×82論理px、背景透明、ドラッグで自由配置し置いた高さを歩行、左クリックで一言、右クリックで呼び出し |

予定の件名は初期状態で隠します。件名を隠しても、通知の存在や時刻は周囲から見えるため、画面共有の前には画面共有モードを手動でオンにする設計です。開始前の通知には、拒否感の出やすい強い色やアラームを使いません。

皮肉は軽いユーモアにとどめます。職務能力・勤務態度を責める言葉や、他の参加者に向けた批判は使いません。「仕事をしているふり」「結局何か決まった？」などの強い発言は、この試作品では採用していません。

性格と頻度は設定ページへまとめ、普段の画面では接続状態・おやすみ・画面共有を優先しています。設定は即時保存し、保存に失敗した場合はその場で知らせます。

外観の切り替えは常駐キャラ・操作画面の2か所のキャラ・トレイとウィンドウのアイコンへ反映します。ウィンドウの位置や大きさは変えず、表示中の予定通知を閉じたり、非表示中のキャラを再表示したりしません。

キャラはドラッグで別モニターを含む任意の位置へ移動でき、離した位置を保存します。クリックは離した時点で判定し、ドラッグでは発言しません。自動歩行は置いた高さの水平移動です。画面端・モニター切断時は利用可能な画面内に補正します。画面上部では吹き出しをキャラの下へ出し、しっぽを上向きにします。スリープ復帰直後に大きく飛ばないよう、1回の移動時間を制限しています。呼び出し・リンク付きの吹き出し・入力フォームの操作中と、連打への反応・クリック・ドラッグ中は立ち止まります。通常のメッセージや通知、別の設定・履歴画面を表示しているだけでは歩行を止めません。キャラ上でポインターを動かすと約0.2秒止まり、動かさずに置いたままなら短い間を置いて再開します。ポインターの位置は操作判定に一時的に使い、記録しません。静かな時間は通知・自動会話だけを休み、アニメーションを継続します。おやすみ・画面共有・非表示中はアニメーションも停止します。設定で表情アニメーションと歩行を変更できます。

吹き出し操作中は雑談を見合わせます。開始前の予定通知は優先します。ファイル履歴はユーザーが設定でオンにした場合だけ取得し、ファイル名と保存先を端末内に保存します。ファイル本文・入力内容は読みません。表示時刻は検出・最近使ったファイルの更新時刻の目安です。記録のない日付も選択でき、空の状態を表示します。

通常メッセージは本文だけを表示し、「○○から、ひとこと」等の見出しを付けません。呼び出し・予定・新着・退勤前通知も見出しと×を付けず、本文と必要な選択肢だけを表示します。クリック直後は通常の雑談と分けた問いかけを表示します。例は「お呼びですか？」「用事は何でしょう？」「何？」です。性格ごとの候補から直近の重複を避けて選びます。「予定を聞く」は呼び出しを閉じ、選択肢のない予定本文だけの吹き出しを表示します。履歴を選ぶと呼び出しを閉じ、今日のファイル名のリンクと「管理画面を開く」を表示します。管理画面へ進むと吹き出しを閉じます。設定は専用画面を開きます。履歴の閉じる操作でアプリは終了しません。画面共有モードでは履歴ウィンドウも隠します。

キーボードではTabで各操作へ移動でき、ボタンにフォーカス枠を表示します。通常のメッセージ・予定の本文はクリック・Esc・時間経過で閉じます。呼び出しと勤怠サイトの選択中は選択肢を操作できます。高コントラストモードとスクリーンリーダーの実機評価は未実施です。

通知領域に常駐します。アイコンの左クリックでキャラを表示／非表示。右クリックのメニューから設定・おやすみ・共有・終了を行います。キャラ・吹き出しの右クリックは呼び出しを出し、「非表示にする」で隠します。復帰時に古い吹き出しは戻しません。会話ルールの詳細は[CONVERSATION.md](CONVERSATION.md)を参照してください。

会話編集は専用の通常ウィンドウです。「会話文」「発生ルール」「全体設定・性格」の3タブで編集します。条件の種類に合う入力欄だけを表示します。保存前は動作へ反映せず、「保存して反映」で検証・JSONへの保存・即時反映を行います。保存失敗や不正データは画面内で説明し、編集中の内容と動作中のデータを保持します。

予定の吹き出しは淡い黄（#FFF3D4）、新着通知は淡い青（#E7F1FF）、会話は白、呼び出しは薄緑です。本文と色で区別します。受信通知はフォーカスを奪わず、検知後すぐ同じ吹き出しに表示します。

コマ補間では前後の画像を別々の透明面で重み付けしてから加算し、完成した1枚を描画します。二重のsource-overで重なる不透明部分が約75%へ薄くなるちらつきを防ぎます。歩行後も現在の向きを維持し、ネイティブウィンドウの移動直後に再描画します。同じ整数位置への再移動や、しっぽ位置が変わらない吹き出しの再描画は省きます。Windowsの合成描画・表示倍率ごとの実機評価は未実施です。

すべての吹き出しでヘッダー領域と×ボタンを削除し、本文の実際の折り返し・改行に合わせて高さを求めます。上下10pxの余白としっぽ12pxだけを足し、ウィンドウの最小100pxへの拡張を使いません。通常のメッセージ・予定・通知は本文や余白の左クリックで吹き出しだけを閉じます。長文は画面の作業領域内に高さを制限して縦スクロールし、スクロールバーの操作では閉じません。呼び出しの選択肢や右クリックは維持します。新着は送信者名・新着件数を表示せず、未読の件数は白い通常会話へ分けます。

予定の一覧・次の予定・開始前通知には「未承諾」「仮承諾」の状態を添えます。予定表と受信トレイを統合し、取得できなかった部分は接続表示と吹き出しに明示します。部分取得時の予定件数は不明として会話に使います。

履歴ウィンドウは初期1180×620、最小1000×500を指定し、カレンダーの日付全行の必要高も確保します。フォント・表示倍率によって実際の最小高は500pxを超えます。時刻・ファイル名・保存先の3列で、ファイル名は初期340pxです。ダブルクリックで既定アプリから開き、取得元は内部互換用に保持して画面には出しません。暦上3か月・15,000件、日別2,000件を上限にします。選択日は青（#1D4ED8）、今日は黄（#FDE68A）で、選択中の今日には黄の枠を付けます。

退勤前通知は初期無効・平日17:00。設定で時刻・文言・URLを保存し、1日1回、10分の有効時間内だけ表示します。薄い橙の吹き出しにWindows起動時刻と経過時間、「勤怠サイトを開く」「あとで」を出します。URL未登録なら設定へ案内します。クリックしたときだけブラウザーで開き、自動送信はしません。

困る・怒る反応は本文をクリックして閉じるまで保持し、その間はキャラの左クリックで上書きしません。右クリックは受け付け、呼び出し中の再右クリックは閉じる操作です。呼び出しの本文・余白クリックはキャラを残して吹き出しだけ閉じます。足元をタスクバーの直上に合わせるため、ウィンドウ下限と歩行の接地線をそろえました。

呼び出しの5択は同じ淡い緑（#E8F0E6）と濃い緑の文字に統一します。先頭に予定＝カレンダー、ファイル起動履歴＝フォルダー、設定＝歯車、非表示＝斜線付きの目、通知を設定する＝ベルのアイコンを置きます。アイコンは同じ線幅・色で描画し、表示倍率に対応した画像を生成します。ホバー・押下は背景を濃く、キーボードのフォーカスは太い枠で示します。ラベルと選択順序は維持します。

予定の吹き出しには「Outlookの予定を開く」を表示し、明示クリックで従来版Outlookの予定表へ移動します。履歴は新しい順に保存先でまとめた直近50ファイルを吹き出しで表示します。リンクは1回クリックで既定アプリから開き、吹き出しは維持します。空の履歴・記録オフ・読み込み失敗でも管理ボタンを残します。予定と履歴の照会は本文クリック・Esc・初期20秒で閉じ、リンク・ボタンのクリックでは誤って閉じません。

単発通知は呼び出しの「通知を設定する」から、同じ吹き出し内の日付・時刻・通知内容とOK／キャンセルで登録します。日付は今日、日付欄のクリックでカレンダーを表示。フォームは自動消去しません。繰り返し通知の編集UI・JSONとは別に保持します。

性格は7種類から見た目とは別に選びます。追加3種は、親しげな関西弁・短く落ち着いた先輩・倒置と短い断句を使う語り手。各217件を用意し、会話編集UIでも選択できます。

寡黙な先輩は、表の発言が「…」だけのとき、その次の行に、全角括弧で少しお茶目な心の声を添えます。同じ吹き出し内で完結し、本文を含めた行数に合わせて高さを調整します。孤高のギャンブラーは、短い断句・倒置・改行で間を作るオリジナルの語り口です。

孤高のギャンブラーのセリフは、体言止めと倒置法を基本とします。案内の意味と数値の読みやすさを保ち、会話編集で変更できます。
