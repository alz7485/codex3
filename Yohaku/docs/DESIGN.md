# デザイン仕様

「余白」は、机の隅に置ける控えめな存在感を目指したデザインです。現行版では普段の吹き出しに問いかけを出し、その下に4つの選択肢を1行ずつ並べます。「予定を聞く」「一言を聞く」は吹き出し内で返し、履歴と設定はそれぞれの専用ウィンドウを開きます。

| ID | キャラクター | 雰囲気 |
|---|---|---|
| A | 余白ノート | 生成りのノート。自然になじむ文具風 |
| B | 事務ロボ | 青い目の小型ロボ。落ち着いた道具らしさ |
| E | まじめなペンギン | ネクタイ姿。端正できっちり |
| F | お茶ねこ | 湯のみに入った猫。水彩調で和やか |

設定ページの先頭にサムネイルを並べ、選択中のキャラに緑色の枠と背景を付けます。キーボードでも選択できます。初期設定はキャラ固有の性格です。Aは気の利く皮肉屋、Bは几帳面な分析役、Eはまじめな応援係、Fはのんびりしたお茶好き。設定で別の性格へ上書きできます。

| 要素 | 仕様 |
|---|---|
| 常駐キャラ | 82×82論理px、背景透明、プライマリ画面の下辺を歩行、クリックで選択式吹き出し |
| 自動通知 | 幅322論理px、予定・雑談とも約1分、音なし、フォーカスを奪わない |
| クリック時の吹き出し | 普段と同じ幅322論理px・しっぽ付き。問いかけの下に4行の選択肢。約1分で閉じる。×・Escで吹き出しを閉じ、右クリックでキャラごと非表示 |
| 選択肢の順序 | 予定を聞く → ファイル起動履歴を見る → 設定を開く → 一言を聞く |
| 予定・一言 | 同じ吹き出しの文章だけを更新。下の4択は残る。タブやカレンダーを吹き出し内に置かない |
| ファイル履歴 | 専用の通常ウィンドウ。左側カレンダーと右側ファイル一覧。今日に戻る・記録の設定を用意 |
| 操作画面 | 初期920×740論理px、通常のWindowsウィンドウ、2ページ構成 |
| 大きな文字・狭い画面 | 設定のページはスクロール可能。Windows高DPIはQtの自動スケーリングを使用 |
| 基調色 | 紙色 #FAFBF9、薄い緑灰 #EDF1EE |
| 操作色 | 深緑 #385C4A、文字 #263B43 |
| キャラ | 採用デザインに合わせた4種の背景透過PNG。縦横比を保って滑らかに縮小 |
| フォント | WindowsではYu Gothic UI。検証画像ではNoto Sans CJK JP |
| モーション | 各キャラ24コマ（表情・しぐさ16＋歩行8）。16ms精密タイマー、加減速・呼吸・揺れ・サブピクセル移動・85msの表情クロスフェード |

予定の件名は初期状態で隠します。件名を隠しても、通知の存在や時刻は周囲から見えるため、画面共有の前には画面共有モードを手動でオンにする設計です。開始前の通知には、拒否感の出やすい強い色やアラームを使いません。

皮肉は軽いユーモアにとどめます。職務能力・勤務態度を責める言葉や、他の参加者に向けた批判は使いません。「仕事をしているふり」「結局何か決まった？」などの強い発言は、この試作品では採用していません。

性格と頻度は設定ページへまとめ、普段の画面では接続状態・おやすみ・画面共有を優先しています。設定は即時保存し、保存に失敗した場合はその場で知らせます。

外観の切り替えは常駐キャラ・操作画面の2か所のキャラ・トレイとウィンドウのアイコンへ反映します。ウィンドウの位置や大きさは変えず、表示中の予定通知を閉じたり、非表示中のキャラを再表示したりしません。

歩行は画面下の利用可能な範囲内に限定します。画面端・プライマリ画面の変更時は位置を補正します。スリープ復帰直後に大きく飛ばないよう、1回の移動時間を制限しています。吹き出し・設定画面・通知の表示中やマウスがキャラに重なる間は立ち止まります。静かな時間・おやすみ・画面共有・非表示中はアニメーションも停止します。設定で表情アニメーションと歩行を変更できます。

吹き出し操作中は雑談を見合わせます。開始前の予定通知は優先します。ファイル履歴はユーザーが設定でオンにした場合だけ取得し、ファイル名と保存先を端末内に保存します。ファイル本文・入力内容は読みません。表示時刻は検出・最近使ったファイルの更新時刻の目安です。記録のない日付も選択でき、空の状態を表示します。

吹き出しの見出しはキャラ名、本文はキャラの言葉です。クリック直後は通常の雑談と分けた問いかけを表示します。例は「お呼びですか？」「用事は何でしょう？」「何？」です。性格ごとの候補から直近の重複を避けて選びます。履歴や設定を選ぶと吹き出しは短い案内だけを返し、対象の画面を開きます。履歴の閉じる操作でアプリは終了しません。画面共有モードでは履歴ウィンドウも隠します。

キーボードではTabで各操作へ移動でき、ボタンにフォーカス枠を表示します。アイコンだけの閉じるボタンには読み上げ用の名前があります。高コントラストモードとスクリーンリーダーの実機評価は未実施です。

通知領域に常駐します。アイコンの左クリックでキャラを表示／非表示。右クリックのメニューから設定・おやすみ・共有・終了を行います。キャラ・吹き出しの右クリックはすぐに非表示にし、自動発言も止めます。復帰時に古い吹き出しは戻しません。会話ルールの詳細は[CONVERSATION.md](CONVERSATION.md)を参照してください。

会話編集は専用の通常ウィンドウです。「会話文」「発生ルール」「全体設定・性格」の3タブで編集します。条件の種類に合う入力欄だけを表示します。保存前は動作へ反映せず、「保存して反映」で検証・JSONへの保存・即時反映を行います。保存失敗や不正データは画面内で説明し、編集中の内容と動作中のデータを保持します。
