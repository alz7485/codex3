# 預けたものを見る（v0.27.0）

ファイルやフォルダをキャラへ1つ渡し、先頭の「ファイルを預ける」または「フォルダを預ける」を選びます。本体は移動せず、その場所への参照だけを保存する一時ランチャーです。移動・PDF印刷の選択肢も継続します。

キャラを右クリックした呼び出しの先頭に「預けたものを見る」を追加しました。いつもの吹き出しにアイコンとファイル名を並べます。

- ダブルクリック：ファイルは関連付けたアプリ、フォルダはエクスプローラーで開きます。Enterでも開けます。単クリックは選択だけです。
- ファイルを右クリック：「フォルダを開く」「削除」。前者は保存先のフォルダを開きます。
- フォルダを右クリック：「削除」のみ。
- **削除も期限切れも、一覧から登録を外すだけです。元のファイルやフォルダ、その内容を削除しません。**

「キャラと通知」の「預けたものの保持期間」で選びます。

| 設定 | リセットの境界（PCのローカル時刻） |
|---|---|
| 1日（初期値） | 預けた後に来る朝5:00 |
| 1週間 | 預けた後に来る月曜0:00 |
| 1ヶ月 | 預けた後に来る1日0:00 |
| 無期限 | 自分で一覧から削除するまで |

経過24時間・7日間・30日間ではなく、カレンダーの境界です。たとえば日曜23:00に1週間設定で預けると、月曜0:00で期限切れになります。境界と同じ時刻に預けたものは次の期間まで保持します。

アプリ起動時・一覧表示時・登録時・最長1分間隔の確認で期限切れを整理します。アプリ停止中やPCのスリープ中に境界を過ぎても、次回の起動・復帰後に古い登録を外します。保持期間の変更は、現在の一覧にも適用します。すでに期限切れで外した登録を復元することはありません。

同じ場所を再び預けると重複させず、預けた日時を更新して先頭へ移します。最大500件です。本体を移動・改名したり、取り外したドライブにある場合は開けなくなることがあります。その場合も本体は変更せず、一覧に参照を残します。必要なら登録を削除し、新しい場所から預け直してください。

保存先は `Data\shelf.json` で、保持期間と参照のパス・種類・預けた日時を保存します。JSONは保存時にバックアップを1世代作ります。不正なJSONは元のファイルを保持し、勝手に上書きしません。ファイル本体やアイコン画像をJSONへコピーすることはありません。

![一覧と設定の表示例](https://raw.githubusercontent.com/alz7485/codex3/main/Yohaku/docs/shelf.png)

一覧を開いていても予定・登録通知・退勤前の通知は妨げません。通知で表示が切り替わっても登録は残り、呼び出しから再び一覧を開けます。新着メールは一覧の上の青い欄に表示し、1分後にメール文だけを消します。リスト・選択中の項目・本文は維持します。閉じるか別の画面へ移るとメール欄のタイマーも停止します。

v0.27.1から、ドロップ後に自動保存などで内容が変わっても「預ける」で現在の場所を登録できます。削除済み・リンク・ファイルとフォルダーの種類が変わった対象は登録しません。移動と印刷は、内容が変わった場合の再ドロップを引き続き求めます。
