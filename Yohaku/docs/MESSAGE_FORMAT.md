# 通知・予定の文字を強調する（v0.25.0）

予定の確認、予定の通知、新着メール、ユーザー登録通知、単発通知、退勤前の通知では、本文の時刻（17:00など）・時間（1時間40分など）・日付・「メール」を青い太字で強調します。本文全体の色と吹き出しの色は従来どおりです。通常のランダムメッセージは自動では強調しません。

通知の登録画面と、吹き出しから単発通知を設定する画面で、文字をドラッグして選択し「太字」や色のメニューを使います。文字の選択がないときは本文全体を対象にします。「標準」で選択範囲の利用者指定を解除します。色は青・緑・赤・紫・橙・黒です。編集欄にもその見た目を表示します。

![表示例](https://raw.githubusercontent.com/alz7485/codex3/main/Yohaku/docs/message-emphasis.png)

本文はこれまでと同じmessageの文字列、装飾は任意のmessage_stylesに保存します。古いJSONに装飾の指定がなくても、そのまま使えます。保存・再起動後も選択した色と太字を保ち、通知を出すときに適用します。利用者の指定がある範囲では自動強調より利用者の指定を優先します。

```json
{
  "message": "提出を17:00までにお願いします。",
  "message_styles": [
    {"start": 0, "length": 2, "bold": true, "color": "#b0443a"}
  ]
}
```

startは本文先頭からの文字数（0始まり）、lengthは対象の文字数です。絵文字も1文字として数えます。色は#RRGGBB、太字はtrue/false、色を変えない場合は空文字です。最大100区間、重複・範囲外は受理しません。本文は従来の1〜1000文字です。単発通知の前後の空白を取り除く場合も、装飾の位置を合わせて保存します。

HTMLを本文として実行する機能はありません。貼り付けたHTMLは通常の文字として扱い、Webリンク・画像や任意のCSSを通知内に読み込ませません。本文は表示前にエスケープし、許可した太字と色だけを生成します。
