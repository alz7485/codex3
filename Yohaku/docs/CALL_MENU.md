# 呼び出しを閉じる（v0.37.2）

キャラを右クリックして出す呼び出しの吹き出しは、選択肢ボタン以外をクリックすると閉じます。吹き出しの本文・余白に加え、デスクトップや他のアプリ、別のYohakuウィンドウのクリックも対象です。吹き出しだけを閉じ、キャラの非表示設定は変更しません。

- 選択肢のボタンは、通常どおり選んだ操作を実行します。
- 外のアプリへのクリックは、そのアプリにも通常どおり渡します。
- キャラを左クリックした場合は、そのクリックで呼び出しを閉じます。直後に別の一言へ置き換えません。
- キャラや吹き出しの再右クリックは、従来どおり呼び出しを閉じます。
- キーボードによるボタン選択は継続します。

外側のクリック検知は、呼び出しの選択肢を表示している間だけ有効です。閉じる・別のメッセージへ切り替わる・アプリを終了すると解除します。クリック位置や他アプリの情報をファイルへ記録しません。

この操作は呼び出しの選択肢に適用します。通知の入力フォーム、ファイル処理の選択肢、預けたもの、通常の予定・通知・メッセージには、従来の閉じ方を引き続き使います。

Windowsのマウスクリック通知を使用し、クリックを横取りして止めません。複数モニターの拡大率の違いを考慮し、ボタンが別ウィンドウに覆われている場合も判定します。古いクリックの通知が、後から表示した入力フォームなどを閉じることを防ぎます。
