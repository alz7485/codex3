# メッセージの表示時間と歩行（v0.28.2）

v0.28.2では、特につづりで足の付け根まで横に滑って見えた点を再調整しました。靴だけを通常の絵から取り出し、体の下に保つ付け根から靴までを短い曲線の脚でつなぎます。左右の足は半周期ずれて動き、右足の接地中は左足を持ち上げ、その逆を繰り返します。靴の切り抜きに本体の明るい色を混ぜないようにしました。

つづり・ビット・ペギーの足の長さと描画倍率に合わせ、移動距離から歩行の周期を進めます。歩幅を小さくし、つづりは約16px/秒、ビットは約20px/秒、ペギーは約18px/秒を上限に加減速します。靴を地面に保ちながら体だけを最大2元画像px（実表示で1px未満）上下させます。コマの補間時間は55ms。逆方向へは完成した姿を左右反転します。元の立ち絵の足の付け根は維持するため、斜め前から見た左右の靴が必ず画面上で交差することは求めません。

![歩行の表示例](https://raw.githubusercontent.com/alz7485/codex3/main/Yohaku/docs/walk-alternation.gif)

| 表示 | 初期の表示時間 |
|---|---|
| 通常の一言・クリック後の会話・未読メールを話題にする雑談 | 20秒 |
| 右クリックの呼び出し・予定の照会・ファイル履歴の照会 | 20秒 |
| 新着メール・予定開始前・登録した通知・退勤前のお知らせ | 1分 |
| 通知の入力フォーム | 自動で閉じない |
| 連打に対する困る・怒る反応 | 本文をクリックして閉じるまで保持 |

通知の表示時間は1分です。会話編集の「通常メッセージの表示時間」を変えても通知には影響しません。入力中のフォームも閉じません。初期値60秒だった旧設定は20秒へ一度だけ移行し、独自に指定した秒数・文章・条件は引き継ぎます。

起動時の待ちは0.05〜0.2秒で、向きの確認・踏み出しを経て約0.4〜0.7秒で歩き始めます。クリック後も以前の長い待ちを持ち越さず、おおむね1秒以内に歩き始めます。停止の小休止は0.4〜1.2秒。移動距離24〜56px、8コマの歩行と補間を保ちます。

通常の一言や、操作ボタンのない通知は表示したまま歩けます。吹き出しはキャラに追従します。呼び出し・リンク付きの予定/履歴・入力フォームでは止まり、操作終了後に速やかに再開します。ドラッグで押している間と連打反応も静止します。ポインターが動いた直後の短い停止は0.2秒で、置いたままなら停止し続けません。

設定・履歴管理・会話編集などの別画面を開いているだけでは止まりません。静かな時間は通知と自動会話だけを休み、歩行・表情は継続します。ドラッグ終了・非表示やおやすみからの復帰後も短い待ちで歩き出します。微小なカーソルの揺れは待ち時間を延長せず、非表示時は未完了のドラッグ状態をリセットします。

歩行オフ・アニメーションオフ・非表示・画面共有・一時停止・各プリセットは引き続き尊重します。

Windowsでの回帰確認には、表示種別ごとのタイマー、メール連続受信時の延長、会話設定変更中の通知/フォーム保持、旧設定と容量上限の移行、起動/クリック後の移動時間・加減速・範囲、選択肢中の静止を含みます。歩行では、左右の足の前後関係の反転、実際に描画した足の接地位置、胴体の位置維持、更新頻度が違っても移動距離と周期が一致することを確認します。配布EXEの自己検査でも3体×8コマの描画を確認します。実Outlookへの接続確認は含みません。
