## 割合の条件

「集計値の割合（%）」を選び、分子・分母・分母の最低計測量・割合の下限と上限を入力します。分子と分母は同じ単位で、分子が全体の一部になる組み合わせを選びます。

![割合条件の編集画面](https://raw.githubusercontent.com/alz7485/codex3/main/Yohaku/docs/ratio-condition.png)

```json
{
  "kind": "metric_ratio",
  "numerator": "daily_active_minutes",
  "denominator": "observed_minutes",
  "minimum_total": 120,
  "minimum": 85,
  "maximum": 100
}
```

計算は分子÷分母×100です。分母が最低計測量に達するまでは成立しません。値を取れないとき、非数・無限大・負数、分子が分母を超えるときも成立しません。分母の最低計測量は0より大きい値、割合は0〜100%です。上限なしは `maximum: null`。AND／ORの一部にも使えます。

操作時間はYohakuが計測した範囲の推定値です。起動前・停止中・スリープなどの未計測時間や、画面の外の活動は仕事の量として評価しません。PC状態の集計をオフにすると、この操作割合の条件は成立しません。

## 残りの予定の集計値

Outlookから取得済みの今日の予定を使います。追加の問い合わせや文書内容の収集はしません。接続済みで5分未満の完全な取得結果だけを使い、一部取得・未接続・古い結果は不明として扱います。

| 識別名 | 内容 |
|---|---|
| `remaining_meetings` | 今日の残りの予定数。進行中も含む |
| `completed_meetings` | 今日にかかる予定のうち終了時刻を過ぎた件数 |
| `remaining_meeting_minutes` | 現在から今日の終わりまでの残りの予定時間。重複は一度だけ数える |
| `overlapping_meetings` | 残りの予定の最大同時件数。隣接する予定は重複と数えない |
| `next_meeting_duration_minutes` | 次に開始する予定の全体の長さ。日を跨ぐ予定では翌日の分も含む |

予定の開始を含み、終了は含まない区間として計算します。今日の終わりちょうどに始まる予定は明日のものとして除外します。終了済みの予定の重なりだけで「残りに重なりがある」とは発言しません。空の完全な予定表では残り0件、次の予定の長さは不明です。予定の時刻を扱うもので、実際の会議参加・終了を検知するものではありません。

ディスクの空き容量は収集・判定しません。新しい数値は会話候補の判定に使い、履歴・テレメトリーに追加保存しません。従来の操作時間の集計保存とOutlookの接続設定に従います。

## 旧JSONの引き継ぎ

`extended_context_version: 1` が追加済みの印です。旧JSONには12話題を一度だけ追加し、既存の文章・条件・重み・無効化・キャラ設定を保持します。同じIDの独自ルールが既にある場合は変更しません。200件の上限に達している場合は、それ以上追加しません。新しい話題の追加で2MiBを超える場合は、話題の追加を見送り、既存の文章・条件をそのまま使用します。移行済みの印も収まらない場合は元の文書を変更しません。追加後に削除した話題は再追加しません。元のファイルは保存操作までは変更せず、保存時にバックアップします。

Windows実機・実Outlookでの動作は未検証です。表示例と自動確認はLinux / Qt offscreenと合成データによるものです。
