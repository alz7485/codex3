# ドラッグ・通知入力のポーズ（v0.28.0）

つづり・ビット・ペギーに次の姿を追加しました。

- キャラをドラッグして移動している間は、頭やしおりをつままれ、手足がぶら下がる姿になります。横に動かすと少し傾き、静かに戻ります。クリックだけや小さな手ぶれでは切り替えません。離すと元の表示に戻り、従来どおり位置を保存します。
- 呼び出しの「通知を設定する」で入力フォームを開くと、メモ帳と鉛筆で書き留める姿になります。鉛筆の位置とまばたきを2枚の画像の間で滑らかに変化させ、入力中は続けます。通知の保存・キャンセル・吹き出しを閉じる・呼び出しへ戻ると終了します。
- 通知入力中にメールが来ると、一時的に手紙を見せ、その後はメモに戻ります。入力内容は維持します。入力中にキャラをドラッグすると、つままれた姿を優先し、離すとメモへ戻ります。
- 「表情・まばたきのアニメーション」をオフにすると、つままれた姿・メモ帳を持つ姿は表示し、揺れ・書き込み・まばたきの動きは停止します。

ドラッグの移動範囲・タスクバーへの吸着・位置の保存は従来どおりです。ファイルをキャラへドロップする操作と、キャラ自体をドラッグする操作を区別しています。

画像は透過PNGの`pickup_poses.png`（3体）と`note_poses.png`（3体×2フレーム）です。通常時は追加の描画タイマーを動かしません。キャラを隠すと入力・ドラッグの表示状態とタイマーを終了します。
