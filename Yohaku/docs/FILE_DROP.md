# キャラにファイルをドロップする（v0.24.0）

キャラへ通常のファイルを1つドロップすると、いつもの吹き出しで処理を選べます。選ぶまではファイルを変更しません。フォルダー、リンク、複数ファイル、WebのURLは対象外です。

| 初期の対象 | 選べる処理 |
|---|---|
| 通常のファイル | 指定フォルダーに移動 |
| PDF | 指定フォルダーに移動 / 印刷 |
| ZIP | 指定フォルダーに移動して解凍 |

「移動先・パスワードなどを設定」または設定画面の「ドロップしたファイルの処理を設定」から登録します。拡張子ごとに移動先、ボタン名、使用する処理を変更できます。初期の移動先は空欄です。未設定の移動・解凍ボタンは無効になり、設定するまで実行できません。

![処理の選択](https://raw.githubusercontent.com/alz7485/codex3/main/Yohaku/docs/file-drop.png)

## 毎月変わるZIPのパスワード

パスワードのひな形に固定部分と変数を入力します。処理を選んだ時点のPCのローカル日時を使います。

| ひな形の例 | 1月 | 10月 |
|---|---|---|
| `固定部分{month}` | `固定部分01` | `固定部分10` |
| `固定部分{month1}` | `固定部分1` | `固定部分10` |

`{year}` は西暦です。パスワードなしのZIPでは空欄にできます。従来のZipCryptoとAES暗号化ZIPを読み込めます。パスワード付きPDF、7z・RARなどZIP以外の解凍はこの版の対象外です。

ひな形はこのPCの `%LOCALAPPDATA%\Yohaku\file_drop_settings.json` に保存します。保存時には同じ場所に `.json.bak` を作ります。設定画面では通常は伏せ字で表示し、必要なら表示できます。値・バックアップはJSON内にそのまま保存されます。アプリのログ・配布ZIP・自己確認レポートへパスワードを出しません。

![編集画面](https://raw.githubusercontent.com/alz7485/codex3/main/Yohaku/docs/file-drop-settings.png)

## 移動・解凍の扱い

移動先に同名のファイルがある場合は上書きせず中止します。別ドライブへの移動ではコピーが完了した後に元ファイルを削除します。通常の移動でコピーに失敗した場合は元ファイルを保持します。

ZIPはまず一時領域で内容とパスワードを検証し、成功してから指定場所へ移動します。移動先には圧縮ファイル自体を残し、その名前から拡張子を除いた新しいサブフォルダーへ解凍結果を配置します。例：`資料.zip` と `資料\`。同名の解凍先への上書きや既存フォルダーへの混合は行いません。

パスワード違い・壊れたZIP・不正な解凍先のパスでは元のZIPを移動しません。ZIP内の外部へのパス・リンク・大文字小文字だけが異なる同名項目を拒否し、解凍は10,000項目・合計1GiBまでです。

PDFは印刷ダイアログでプリンター・用紙設定・ページ範囲を選びます。キャンセルすれば印刷しません。対象は256MiB以内・1,000ページ以内です。PDFファイルそのものは変更しません。

ファイル処理は同時に1件です。移動・解凍は別スレッドで行い、処理中の終了操作は完了待ちになります。処理選択中の吹き出しは自動では閉じず、キャラも立ち止まります。通常の一言は20秒、通知は1分のままです。新着メールは選択肢を消さず、同じ吹き出し内に表示します。単発通知を入力中はドロップを受け付けません。

## JSONの形式

以下は説明用の例です。実際の移動先と固定部分は利用者が設定します。

```json
{
  "schema_version": 1,
  "enabled": true,
  "rules": [
    {
      "id": "zip",
      "label": "ZIP",
      "extensions": [".zip"],
      "destination": "C:\\Yohaku\\受け取り",
      "password_template": "固定部分{month}",
      "actions": [{"action": "move_extract", "label": "移動して解凍する"}]
    }
  ]
}
```

処理IDは `move`・`print_pdf`・`move_extract` だけです。`print_pdf` はPDF専用、`move_extract` はZIP専用のルールで使えます。`extensions` の `*` は他に一致するルールがないファイルです。拡張子は小文字で記載し、ルール間で重複させません。

ルールは最大30件、拡張子は1ルール30個、ボタン名は60文字までです。JSONから実行ファイル・スクリプト・シェルコマンドを登録する機能はありません。直接JSONを編集した場合は次のドロップ時に読み直します。無効化中から直接JSONで有効化した場合はアプリを再起動するか、設定画面から有効にしてください。
