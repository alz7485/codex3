# 余白 / YOHAKU

アプリ名は **余白（YOHAKU）**。仕事の合間にそっと声をかける、小さな同僚です。
短い呼び名にして、通知・設定・Windowsのアプリ一覧でも読みやすくしました。

アイコンは、深緑の吹き出しと生成りのノート、小さな金色のしおりです。
会話、予定、ファイル履歴の3つを、会社のデスクトップになじむ文具の印象にまとめています。
キャラクターを変更しても、アプリ本体・ウィンドウのアイコンは固定です。
トレイはこれまでどおり選んだキャラクターを表示します。

- 表示名：余白 / YOHAKU
- Windows実行ファイル：`Yohaku.exe`
- 設定・履歴の保存先：`%LOCALAPPDATA%\Yohaku`（以前の設定を引き継ぎます）
- PNG：`companion/assets/app/yohaku.png`
- Windows ICO：`companion/assets/app/yohaku.ico`（16 / 24 / 32 / 48 / 64 / 128 / 256px）
- アプリ情報と版：`companion/metadata.py`
- Windowsの製品名・ファイル説明：`packaging/windows_version_info.txt`
