# デスクトップの小言キャラクター — 開発引き継ぎ

このZIPを新しいChatGPT/Codexチャットに添付し、「仕様を読んで設計・実装を開始して」と依頼してください。

## 目的
Windowsで常駐する、ジョークと実用性を兼ねた小さなデスクトップキャラクター。**外部AI連携はしない**。Outlookの予定を読み取り、状況・履歴・性格に応じてルールベースで自然に話しかける。

## 確定要件
- Python製Windowsデスクトップアプリ。
- AI APIや外部LLMに依存しない。セリフはテンプレート、条件分岐、重み付け、履歴で選択する。
- Outlook予定表と連携し、当日の予定や開始前の通知を行う。
- ジョーク・小言・皮肉を楽しめるキャラクターとする。通知アプリだけにはしない。
- 画面上にキャラクターと吹き出しを表示する。
- 性格の候補：毒舌・皮肉屋、元気・応援型、冷静・事務的、怠け者・脱力系。
- 状況の候補：PC起動時、朝、会議前、会議後、連続会議、予定なし、長時間作業、退勤時間帯。
- 同じ発言を連発しない。直近履歴やイベント回数でセリフを変える。
- 通知頻度・静音時間・重要予定通知と雑談の優先順位を制御する。
- 予定件名などの機密情報を外部へ送信しない。

## 未確定（実装前に確認）
- キャラクターの配置：画面隅に固定か、自由に歩き回るか。
- キャラクターの外観（画像、アニメーション、サイズ）。
- 発言はテキスト吹き出しのみか、音声読み上げも必要か。
- Outlook環境：従来版Outlookか新しいOutlookか。COMは従来版が基本。会社のポリシーも確認。
- 通知の時刻・頻度、予定の公開範囲、終了時刻後の発言条件。
- PC操作履歴の収集範囲。監視対象は必要最小限にし、明示的に設定する。

## 技術方針（提案であり確定ではない）
- Windows 11 / Python 3.11 / PySide6 または PyQt5 / PyInstaller onedir。
- 従来版Outlookが利用できる場合、pywin32のOutlook COM (`GetNamespace('MAPI')`, CalendarフォルダのItems) を第一候補とする。繰り返し予定・タイムゾーン・キャンセル・終日予定に注意。
- 新しいOutlookのみの場合はMicrosoft Graph等を検討するが、会社の承認や認証が必要になり得る。無断で認証回避しない。
- 予定取得と表示は分離し、Outlookが起動していない・取得に失敗した場合もジョークキャラとして動く。
- `rules.json` / `phrases.json` / `settings.json` / 履歴用SQLiteまたはJSONの分離を検討。
- スケジューラ：イベント優先度、発言間隔、同一予定の重複通知防止、履歴・重み付き抽選。
- 画面共有や人が近くにいるときの予定タイトル漏洩に配慮。非表示モードも用意。

| 会議繰り返し | またこの会議ですね。すっかり常連です。 |

## ルールベース疑似人格の構造
1. 予定・時刻・ユーザー操作（許可されたもののみ）を取得。
2. 状態を推定：忙しい／会議前／会議中／長時間作業など。
3. 条件に合う発言候補を抽出。
4. 性格、機嫌（内部状態）、優先度、履歴、重み、クールダウンを考慮して選択。
5. キャラクターの吹き出しで表示。
6. イベントと発言履歴を記録。必要に応じて同一予定への反応を変える。

## 開発上の重要な注意
