# Yohaku v0.14.4 修正内容

2026年10月24日。v0.14.3の通常監査で確定した6件の修正と、呼び出し操作の変更です。今回は修正対象の回帰検証であり、通常監査の再実施ではありません。

| 対象 | 修正後の動作 | 回帰確認 |
|---|---|---|
| YOH-001 予定通知の保存失敗 | 保存失敗時は通知済み状態と表示間隔を戻し、有効時間内に再試行します。 | JSON置換の一時失敗、無関係の保存、再起動後の再試行、正常配信後の重複抑制 |
| YOH-002 ファイル履歴の保存失敗 | DBへの保存が成功してから重複除外と取得基準を更新します。 | Office・Recent Items各経路、5秒・20秒後の復旧、1件だけの保存 |
| YOH-003 Office取得失敗 | 取得できなかったOfficeアプリを区別し、既知の文書を閉じた扱いにしません。履歴画面に再試行の案内を表示します。 | 実adapter＋模擬COMでWordのBusy→復帰、初回取得不能からの基準作成、実際の閉じ直し後の再オープン |
| YOH-004 時刻変更・取消 | 会議の識別子で最新版の案内を選んでから日付を絞ります。開催回の元の日付を使って、繰り返し予定の別の日を保持します。 | 同日・翌日への変更、変更後の取消、古い取消、予定表との統合、例外開催回、GlobalObjectId、比較可能な更新番号 |
| YOH-005 長いメッセージ | 吹き出しを対象画面の作業領域内の高さに収め、長文を縦スクロールできます。スクロールバーの操作では閉じません。 | 80行の本文、600・800・1040px高の画面、末尾までのスクロール、短文に戻したときの縮小 |
| YOH-006 履歴カレンダー | 日付全行と下の操作の必要高を確保します。表示倍率・フォントによって、ウィンドウの実際の最小高が500pxを超えます。 | 1000×500へのリサイズ要求、検索あり・なし、全日付セルの表示、下のボタンとの非重複、30日のクリック選択 |

「予定を聞く」は呼び出しを閉じてから、選択肢のない淡い黄色の吹き出しを表示します。本文のクリック・Esc・約1分で閉じます。「ファイル起動履歴を見る」「設定を開く」は呼び出しを閉じ、専用ウィンドウだけを開きます。「用事はない」「非表示にする」と右クリックの呼び出しは維持します。

188件の自動テストをLinux / Qt offscreen・合成データ・模擬COMで実施。2つのZIP統合後にも同じテストを実施し、全ファイルのハッシュ、ZIPのCRC、直接onedirコマンドの5行、利用者の設定・履歴を含まないことを確認します。

Windows実機、実Outlook・Office、表示倍率ごとの実表示、Windows EXEのビルド・起動は未検証です。会議識別子・更新番号・開催回の情報が欠ける環境や、確認上限を超える会議案内は完全な履歴の復元を保証できません。取得の警告は画面に表示します。実機確認は[Windows確認手順](WINDOWS_CHECKLIST.md)に従ってください。
