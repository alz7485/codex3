# 履歴と吹き出しの表示量（v0.26.2）

履歴管理画面の行の上下余白を9pxから3pxへ、吹き出しの履歴リンクは5pxから2pxへ減らしました。文字サイズ・ファイル名の列幅・ダブルクリック操作・日付選択・全履歴検索は維持します。

予定・通知本文の約200px、履歴リンク一覧の210pxの固定上限を撤廃しました。内容が多いほど吹き出しが高くなり、画面内で使える高さを超えた部分だけスクロールします。履歴の本文と一覧は高さを分け合い、「管理画面を開く」のボタンも残します。短い内容に戻すと高さも縮みます。横長のファイル名は末尾を省略し、横スクロールで縦の領域を使わないようにしました。

Windows上の既存レイアウト・操作テストとEXEビルド／自己確認で検証します。
