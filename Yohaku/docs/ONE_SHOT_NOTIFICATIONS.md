# 吹き出しで登録する単発通知（v0.19.1）

右クリックの呼び出しは、予定を聞く → ファイル起動履歴を見る → 設定を開く → 通知を設定する → 非表示にする、の5択です。「用事はない」は削除し、呼び出しの本文・余白をクリックして吹き出しだけ閉じます。再右クリックとEscでも閉じます。ボタンのクリックは各操作を実行します。

「通知を設定する」を押すと、同じ吹き出しに問いかけと日付・時刻・通知内容・OK・キャンセルを表示します。

- 日付は通常、今日です。日付欄の文字部分・右端のどちらを押してもカレンダーが開き、過去の日付は選べません。キーボード編集でも最小日付を守ります。
- 時刻は24時間表記の `HH:mm` を全体で入力・貼り付けできます（例：09:05、17:30）。通常は現在時刻の次の分が初期値。今日は次の分以降、明日以降は00:00〜23:59を指定できます。未完成・不正・過去の時刻ではOKを押せません。秒は指定せず、PCのローカル日時に従います。
- 入力中も期限を更新し、保存直前にも再確認します。23:59に新規入力を始める場合は翌日00:00が初期値。入力中に選べる日付が変わったときは、日付か時刻を選び直すまで登録を止め、本文を保持します。
- 通知内容は1〜1000文字、未配信の登録は最大100件。過去・現在の日時、空欄、不正な入力は登録せず、入力を保持して説明します。
- OKで保存後、日時と「一度だけお知らせします」の確認文へ切り替えます。二重クリックでも追加登録しません。
- キャンセル・Esc・右クリックによる呼び出しへの移動は、保存せず終了します。
- フォームは自動で閉じません。本文や入力欄をクリックしても入力中は閉じず、キャラの左クリックや予定・退勤前通知で入力を上書きしません。入力中の新着メールはフォーム内の淡い青の欄へ即表示します。通常の新着メール通知は従来どおりです。

![呼び出しと単発通知の登録例](https://raw.githubusercontent.com/alz7485/codex3/main/Yohaku/docs/one-shot-reminder.png)

これは設定の通知ロジック・繰り返し通知とは別の、指定した年月日・時刻で一度きりのお知らせです。登録はローカルの `%LOCALAPPDATA%\Yohaku\one_shot_notifications.json` に保存します。PC再起動・アプリ再起動でも残ります。配布ソースZIPにはこのファイルとバックアップ・一時ファイルを含めません。通知内容の外部送信やOutlookへの登録は行いません。

指定時刻以降、通常のアプリの確認周期で淡い青の通知吹き出しに内容を表示し、本文クリックで閉じます。同時刻の複数件は、先の吹き出しを閉じた後に順に表示します。配信した登録は保存から除き、翌日・再起動後も繰り返しません。配信済み状態を保存できない場合は通知を消費せず再試行します。

非表示・画面共有モード・通知の一時停止・静かな時間・入力中は配信を保留します。休止・アプリ停止中に時刻を過ぎた場合も、起動後に表示できるタイミングで知らせます。過去の単発通知を10分で破棄しません。アプリが停止中の時刻そのものに通知する機能やWindowsのタスク登録はありません。

保存失敗時は登録フォームと入力を維持します。不正な保存ファイルは保持し、追加で上書きせずフォーム内に説明します。通常の繰り返し通知編集画面では、この単発通知を変更しません。

確認はLinux / Qt offscreenでの自動テストと合成データによる表示例です。Windows実機のフォーカス、カレンダーポップアップ、休止復帰を含む操作は未検証です。
