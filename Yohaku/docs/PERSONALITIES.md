# Yohakuの7つの性格（v0.21.0）

設定の「キャラの性格」から、見た目とは独立して選びます。つづり・ビット・ペギー・きなこのどれにも、7種すべてを組み合わせられます。選択は保存され、再起動後も引き継ぎます。

| 性格 | 雰囲気 | 一言の例 |
|---|---|---|
| 控えめな皮肉屋 | 丁寧な口調に、小さな皮肉 | ひと息どうぞ。キーボードは逃げません。 |
| 冷静な案内役 | 短く正確、ときどき不器用 | 短い休憩をおすすめします。 |
| 元気な応援係 | 礼儀正しく、前向きに応援 | ここまでお疲れさまです。少し背伸びをどうぞ！ |
| のんびりした同僚 | マイペースで、急かさず寄り添う | ちょっと、ひと息つきませんか。 |
| 馴れ馴れしい関西弁 | 距離が近く、気さくにツッコむ同僚 | ちょっとひと息つこか。こっちは逃げへんで。 |
| 寡黙な先輩 | 普段は短く、ときどきお茶目な心の声 | …<br>（呼ばれると、少しうれしい。） |
| 孤高のギャンブラー | 一人で盤面を読み、勝ち筋と引き際を大切にする | 決めよう……次に切る一枚。<br>勝負を動かす、小さな一手。 |

「キャラクターに合わせる」では、つづり＝控えめな皮肉屋、ビット＝冷静な案内役、ペギー＝元気な応援係、きなこ＝のんびりした同僚です。会話編集の「全体設定・性格」で、このキャラごとの初期の組み合わせも変更できます。

追加3種の文章はオリジナルです。「孤高のギャンブラー」は文の順序を入れ替え、短い断句や間を用います。案内の日時・件数・リンク・ボタンは通常の表示を保ちます。

## 話題と動作

76話題すべてを7種の性格に用意しています。各217件、合計1,519件。v0.18.0で543件追加しました。普段の一言、呼びかけ、予定案内、ファイル履歴の案内、連打への反応、新着・未読メール、CPU・メモリ・電源・ファイル記録など、各話題に対応します。

発言間隔・条件・表情・重み・再発言の間隔は全性格で共通の話題設定に従います。初期の自動発言間隔は約10分です。「寡黙な先輩」は文章を短くした性格です。発言を減らしたい場合は、通常の設定や話題ごとの頻度を変更できます。単発通知で入力した内容や、登録通知の本文は、利用者が入力した文章のまま表示します。

新着メールのセリフも性格に応じた口調ですが、送信者・件名・内容・新着件数は含めません。未読の件数は従来どおり通常会話の候補に含めます。勤務終了までの残り時間は「1時間40分」などの表記です。

## 編集・旧設定の読み込み

会話編集の「セリフ」で性格を選び、話題ごとの文章を編集できます。保存後に反映し、JSONの入出力にも対応します。

`personality_expansion_version: 1` は追加済みの印です。旧4性格のJSONには読み込み時に不足している3性格の文章を加えます。元のファイルは保存操作までは変更しません。元の4性格の編集内容、条件、話題の有効無効、キャラとの組み合わせを保持します。

利用者が追加した独自の話題には既定の文章がないため、「控えめな皮肉屋」に登録されているその話題の文章を、新3性格の編集用初期値としてコピーします。好きな口調へ編集してください。削除済みの任意話題は追加し直しません。性格を新規追加する処理では、追加済みの性格の文章は保持します。不完全・不正なJSONは従来どおり検証エラーとして扱います。


## 口調と心の声の調整（v0.18.1）

「孤高のギャンブラー」は180件を改稿しました。結論と理由の順を入れ替える、短く区切ってから判断する、改行で間を置く、といった方法で語り口を強めています。オリジナルの文章です。件数・時刻などの差し込み値と案内の意味は保ちます。

「寡黙な先輩」は181件のうち32件に、少しお茶目な心の声を添えました。普通に短く返事する文章も残しています。例：

```text
…
（呼ばれると、少しうれしい。）
```

```text
…
（お茶の用意だけは早い。）
```

心の声は、表の発言が「…」だけのときに限り、次の行に全角の括弧で表示します。通常のセリフには心の声を添えません。通常の文章の選択時に、そのバリエーションが選ばれた場合に出る仕組みです。32/181は収録文章の内訳で、すべての話題で同じ確率という意味ではありません。別の通知やウィンドウを追加せず、発言間隔・表示時間・連打時の待機も従来の設定に従います。会話編集では本文と心の声を一緒に編集でき、心の声だけを消すこともできます。

`personality_wording_version: 1` は今回の文章更新を適用済みの印です。`companion/assets/dialogue/personality_wording_v1.json` の対応表に従い、同じ性格・同じ話題にある旧既定の文章と完全一致したものだけを更新します。編集済みの文章・並び順・削除済みの文章や話題を保持し、独自の話題は変更しません。元ファイルは保存操作までは変更しません。更新後に心の声を消した場合や旧文章に戻した場合も、適用済みの印を保持していれば再更新しません。

Windows実機での表示・操作は未検証です。表示例はQt offscreen上の実装ウィジェットを使用しています。

## 無言のときだけの心の声（v0.18.2）

`senior_silence_version: 1` で、旧既定の心の声付き32件を「…」と心の声の形式へ一度だけ更新します。編集済みの保存内容は保持します。実際の表示では、先輩のセリフ末尾に改行と全角括弧で記述した心の声は、その前の表の発言が「…」の場合だけ出します。通常発言に添えた心の声は表示せず、表の発言だけを出します。心の声は自動生成・別通知にせず、JSONと会話編集から変更できます。

## 孤高の債務者への改名（v0.18.2）

旧名称「倒置法の使い手」から「孤高の債務者」へ変更しました。181件中169件はそのまま、雑談など12件に一人で考える姿勢・返済・節約を追加しました。返済や節約はキャラ自身の設定として語ります。旧名称の設定・キャラとの組み合わせ・編集済み文章は読み込み時に新名称へ引き継ぎます。`debtor_voice_version: 1` が既定の12件の更新済みの印です。個別に編集した文章は保持します。

## 体言止めと倒置法（v0.18.3）

孤高の債務者は181件を見直し、「決めておきたい……次の一手。」「近づいている……予定の時刻。」のように体言止めと倒置法を基本とする口調へ調整しました。仕事の案内・数値の意味、返済や節約を語るキャラ自身の設定を保ちます。

`debtor_style_version: 1` は今回の既定文章の更新済みの印です。旧既定と同じ性格・話題で完全一致する文章だけを更新し、編集済みの文章・順序・削除・独自話題は保持します。元のファイルは保存操作までは変更しません。会話編集で自由に変更できます。

v0.19.1で12話題に各3件ずつ、7性格で計252件を追加しました。先輩の心の声付きは従来の32件と新規2件の計34件で、すべて表の発言が「…」のパターンです。
