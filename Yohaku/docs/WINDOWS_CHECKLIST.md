# Windowsでの確認手順

このチェックは未実施です。社内環境での利用可否の認定を意味しません。合成予定や個人情報を含まないテスト予定表で確認してください。

1. Windows 11とPython 3.11/3.12で依存関係を導入し、READMEの直接コマンドで起動する。
2. 100%・150%・200%表示で文字やボタンが切れないか、設定ページをスクロールできるか確認する。
3. キャラがタスクバーを避けて表示され、吹き出しが操作中のアプリからフォーカスを奪わないことを確認する。
4. 画面の抜き差し、プライマリ画面の変更、タスクバー位置変更でキャラが画面内に残ることを確認する。
5. 従来版Outlookを開き、接続する。日本語・英語など実環境のWindows地域設定で日付フィルターが機能するか確認する。COM権限が拒否された場合は接続失敗が表示されることを確認する。
6. 10分後以内に始まるテスト予定を作り、2分以内の再取得後に一度だけ通知されることを確認する。予定の件名は初期状態で表示されないことを確認する。
7. 同じ開催回でアプリを再起動して重複しないか、翌開催回の繰り返し予定は通知されるか確認する。例外変更・キャンセルした開催回、終日予定、複数日の予定も確認する。
8. WindowsとOutlookのタイムゾーンが異なる環境や夏時間の境界付近で、StartUTCの変換と通知時刻を確認する。
9. 件名表示をオン→オフにし、表示・吹き出しから即時に件名が消えること、history.jsonに件名が入らないことを確認する。
10. おやすみ・静かな時間・画面共有モード中に自動通知が出ないことを確認する。画面共有モード解除と終了はWindowsのトレイから行う。
11. Outlookを終了・切断し、エラー時に以前の予定が通知されないことを確認する。Outlook起動後の再接続も確認する。
12. スリープ・復帰後、開始済みの予定が後追い通知されないこと、静かな時間が正しく適用されることを確認する。
13. 二重起動が防止されること、終了後に再起動できることを確認する。
14. ONEDIR_COMMAND.txtの直接コマンドでonedirを作り、Pythonがインストールされていない別のテスト端末でフォルダー全体から起動確認する。
15. 「キャラと通知」でA/B/E/Fを順に選び、常駐キャラ・操作画面・トレイアイコンが即時に切り替わることを確認する。再起動後も選択が残り、「キャラクターに合わせる」では固有の性格になり、個別指定した性格は保持されることを確認する。
16. Outlook接続中・取得中・通知表示中・おやすみ中・画面共有モード中にキャラを変え、接続や通知履歴が失われず、非表示中のキャラが勝手に再表示されないことを確認する。EXEにも4種すべての画像が同梱され、背景が透過されるか確認する。
17. A/B/E/Fの待機・まばたき・笑顔・お知らせ・歩行を確認する。Fは湯のみごと揺れて移動する。静かな時間の外で設定画面を閉じ、2〜4秒程度後の歩行を確認する。
18. キャラを右クリックして「お呼びですか？」等の問いかけの下に、「予定を聞く」「ファイル起動履歴を見る」「設定を開く」「非表示にする」「用事はない」が縦5行で出ることを確認する。一言は左クリックで表示し、予定も同じ吹き出し内で返し、履歴と設定はそれぞれ専用画面を開くことを確認する。約1分で閉じ、Escは吹き出しだけを閉じること、呼び出しの「非表示にする」はキャラごと非表示にすることも確認する。
19. 初期設定オフではOffice文書一覧や最近使ったファイルの取得を行わず、files.sqlite3を作らないことを確認する。オンにしてから保存済みExcelブックを開き、ファイル名と完全な保存先が記録されることを確認する。Word・PowerPointも確認する。
20. 同名で保存先が違うファイル、閉じて20秒以上後に開き直すファイル、複数Officeインスタンス、Officeが応答しない状態、ネットワーク共有上のファイル、最近使ったファイルの記録が無効な状態を確認する。取得漏れがある条件を記録する。本文や入力内容は保存されないことを確認する。
21. カレンダーから昨日・今日・記録のない日を選び、選択した日の記録だけが表示されることを確認する。深夜と夏時間の境界付近でも日付が混ざらないか確認する。
22. 記録をオフにして取得が止まること、保存済み履歴は閲覧できること、削除後に古い取得結果が戻らないことを確認する。3か月・15,000件の保持制限も確認する。

Outlookの読み取りが社内設定で制限されている場合は、設定を変更したり認証を回避したりせず、接続なしのキャラクターとして利用するか、社内の導入担当者に確認してください。

23. キャラ・吹き出し本文を右クリックして呼び出しを出し、「非表示にする」でキャラと吹き出しが隠れ、通知領域のアイコンは残ることを確認する。アイコンの左クリックでキャラだけを戻し、再度左クリックで非表示、右クリックで設定・終了を選べることを確認する。
24. 静かな時間外に約10分待ち、約1分表示される自動会話を確認する。手動で一言を聞いた後は次の自動会話が約10分後になること、会議中・非表示・設定操作中には自動雑談を出さないことを確認する。
25. 朝・昼・午後・夕方、月曜・金曜・週末、予定の前後の定型文を確認する。4キャラを切り替え、固有の言葉遣いと話題に合った表情が出ることを確認する。旧設定からの移行で間隔が一度だけ10分に変更され、その後選んだ間隔が保持されることも確認する。
26. 約60fpsを目安に歩行の8コマ、加減速、待機時の呼吸としぐさが滑らかに見えるか、CPU使用率が社内端末で許容範囲か確認する。画面スケーリングとスリープ復帰後も大きく飛ばないことを確認する。

27. 「キャラと通知」→「会話文・発生ルールを編集」、およびトレイの「会話を編集」で編集画面を開く。日本語・改行入りのセリフ、独自話題、時間帯・曜日・予定前後、表情、会話間隔、吹き出し秒数を変更し、「保存して反映」で次の会話に反映されること、再起動後も保持されることを確認する。
28. 空のセリフや不正な条件では保存できず、動作中の会話が変わらないことを確認する。保存先を書き込み不可にした場合のエラーと内容保持、JSONの入出力、初期値へのリセット、バックアップからの復元も確認する。
29. 未保存の編集を閉じる・終了すると保存／破棄／キャンセルを選べ、キャンセルで編集が残ることを確認する。非表示・画面共有では編集画面も隠れ、開き直すと編集中の内容が残ることを確認する。

30. Windowsで操作を止めた時間と操作あり推定時間、日別累計、日跨ぎ、スリープ復帰を確認する。アプリ停止・計測できない時間を足さず、初回起動で「昨日使っていない」と言わないことを確認する。usage.jsonには各日の集計と使用日だけがあり、入力内容やファイル名が入らないことも確認する。
31. 取得可能なOffice文書数、ユーザーとPublicのデスクトップ件数、履歴オン時の同じ保存先の開き直し回数を確認する。取得失敗・古い値をゼロ扱いにしないこと、勤務時間が08:30〜17:30として条件に反映されること、今週と当日の予定数も確認する。
32. 従来版Outlookに接続し、テスト用メールと会議依頼を受信する。受信イベントで通知され、イベントが使えない場合も約1秒の確認で検知すること、既存メールは出さないこと、同じ受信でイベントと確認の二重通知をしないことを確認する。新着は送信者名と新着件数を出さず、送信者名・アドレス・件名・本文を取得しないことも確認する。
33. 予定の淡い黄、新着の淡い青、会話の白、呼び出しの薄緑を確認する。新着が10分の会話間隔や呼び出し操作を待たないこと、非表示・共有・おやすみ・静かな時間中は表示せず復帰後にもまとめて出さないことを確認する。

34. キャラを左ドラッグして移動し、別モニター・負の画面座標・100%/150%/200%の境界で確認する。ドラッグでは発言せず、クリックは離したときだけ発言すること、再起動で離した位置が復元され、モニター切断後は画面内へ戻ることを確認する。
35. 画面上端では吹き出しが下に出てしっぽが上を向くこと、通常メッセージは本文だけで予定と新着には見出しが残ることを確認する。
36. A/B/E/Fの歩行時・停止時・反転時のちらつきや残像を、明暗の壁紙と複数表示倍率で確認する。コマ切り替え時に全体が薄くならず、停止時に向きが急反転しないことを確認する。Windows実機の描画とCPU使用率は別途検証が必要。

37. 通常メッセージの×がなく、1〜3行の内容に合わせて高さが変わり、本文・余白のクリックで吹き出しだけが閉じることを確認する。右クリックで呼び出し、すべての吹き出しで見出しと×がなく、呼び出しのボタン・退勤前の選択肢・Escが使えることも確認する。
38. 新着は届いたことだけを知らせ、送信者名と新着件数を出さないこと、既定の受信トレイの未読数がOutlookと合うこと、未読5件以上で通常会話の候補となり、即時通知にはならないことを確認する。既読化で条件から外れ、古い値を使わないこと、JSON編集からしきい値・優先度・セリフを変えられることも確認する。
39. 2つのソースZIPを同じ場所に展開し、共通ファイルを上書きして統合後、ONEDIR_COMMAND.txtの直接コマンドでビルドできるか確認する。

40. 未承諾・仮承諾・承諾済みの会議を作り、予定表に未反映の案内を受信トレイに残して、一覧と開始前通知を確認する。未承諾の状態が表示され、同じ会議が予定表にもある場合は1件だけとなり、承諾後も重複通知しないことを確認する。キャンセル・辞退・古い案内、繰り返し予定、件名表示オフ、複数の地域設定、個別の取得エラーも確認する。既読化・応答・予定の作成が起きないことを確認する。

41. 履歴のファイル名欄が広く、取得元列がないこと、ダブルクリックで保存先の実ファイルを既定アプリから開けることを確認する。移動・削除済みのファイル、UNC共有、関連付けがないファイルも確認する。
42. 3か月前の同日・月末・うるう年の境界と15,000件の上限を確認する。カレンダーの選択日が青、今日が黄、今日を選択した場合は黄の枠が付くことを100%・150%・200%で確認する。
43. 退勤前通知を有効にし、初期17:00、平日だけ、独自時刻・メッセージ・利用者の勤怠URLを保存できることを確認する。1日1回、再起動後も重複せず、非表示等で抑制され、10分超の後追いがないことを確認する。URL未登録なら設定へ、有効なら選択時だけブラウザーが開き、あとでは閉じることを確認する。PC起動時刻と経過時間をWindowsの実値と比べ、スリープと高速スタートアップでも目安の表示を確認する。

- A/B/E/Fの待機時に正面、歩行中に進行方向を向くこと、ペンギンの翼が正面の各表情で左右1本ずつであることを確認する。
- 5秒以内に左クリック4回で困る、7回で怒る、反応の本文をクリックするまで追加の左クリックで上書きせず、自動では消えないことを確認する。ダブルクリックの各クリックも数え、右クリック・ドラッグ・吹き出しのクリックでは増えないことを確認する。
- 会話編集で回数・秒数・セリフ・表情・有効無効を変更して保存し、即時に反映することを確認する。アニメーションオフでも静止表情が変化・復帰し、再びオンにしたときに古い怒り顔が復活しないことを確認する。

- 下端へドラッグしてタスクバー直上まで下げられること、歩行中の足元・中心が跳ねず、正面への切り替え時に前のコマが反転しないことを確認する。高DPI・別モニター・タスクバー自動非表示も実機で確認する。
- 呼び出しの再右クリックで吹き出しが隠れ、「用事はない」でキャラを残して吹き出しを閉じることを確認する。
- 困る・怒る反応を表示したまま多数回クリックしても本文・回数が変わらず、本文をクリックして閉じると再開することを確認する。右クリックで呼び出しても停止は維持し、「用事はない」で明示的に解除できることを確認する。新着通知後は未確認の反応へ戻ることを確認する。
- きなこの通常・正面・各表情の開いた目が琥珀色で縦長の瞳孔になり、まばたきや閉じ目は閉じたままであることを確認する。

- 同じ「困る」を閉じてすぐクリックしても同じ段階を繰り返さず、30秒後なら再発生することと、怒る段階への変化は別に扱うことを確認する。
- 下端16px以内で離すと吸着し、吸着オフや範囲外では自由な高さを維持することを高DPI・別モニターで確認する。歩き出しの向き確認・前傾・停止姿勢・正面復帰も確認する。
- プリセットの保存・再起動・個別変更と、Outlookやファイル記録設定を変えないことを確認する。プレビューが本番の通知済み状態・連打判定・履歴を変えないことを確認する。
- 旧設定で送信者表示がオンだった状態から更新し、送信者を取得・表示せず「メールが届きました。」のみとなること、連続受信で本文を次々に差し替えないことを確認する。
- 違う日付の同名ファイルが全履歴検索で見つかること、保存先でも検索できること、検索を消すと選択日へ戻ること、検索結果の日付とダブルクリック起動を確認する。
- 「通知を登録・編集」で、月末の最終平日と15日までの最終平日、毎日・曜日・日付の条件を保存し、次回対象日を確認する。平日が月〜金で祝日を含むこと、短い月やうるう年・年末・基準日1日の前月繰り上げを確認する。
- 登録通知の時刻を直後に設定し、青い吹き出しにメッセージだけが出ること、再起動で重複しないこと、同時刻の登録が順に出ること、既存の吹き出し・未確認の連打反応を読み終えるまで待つことを確認する。非表示・共有・静かな時間・おやすみ・スリープ復帰と、10分超の後追いがないことも確認する。
- 登録通知のJSON・バックアップ、編集取消・保存失敗・壊れたJSON、未保存での閉じる／終了の選択を確認する。利用者の通知JSONが配布ZIPに含まれず、Outlookを切断しても登録通知が使えることを確認する。

- 歩行オン時に2〜5秒の小休止を挟み、24〜56pxずつ短く往復することを確認する。吹き出し・設定・履歴の表示中は停止し、操作・ポインターの停止待ちが終わると約1〜2秒で歩き出すこと、歩行オフ・控えめ／通知だけ・静かな時間・非表示中は勝手に歩かないことを確認する。

- ポインターをキャラ上で動かすと約2秒立ち止まり、そのまま置いても永久停止せず歩くことを確認する。クリックを押している間とドラッグ中、未確認の困る・怒る反応は、経過時間にかかわらず停止を維持する。
