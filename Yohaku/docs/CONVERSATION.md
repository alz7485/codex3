# キャラの性格と会話

| キャラ | 性格・言葉遣い | 代表的な一言 |
|---|---|---|
| つづり（ノート） | 気の利く記録係。丁寧な口調、文具に絡めた軽い皮肉 | 「急がば、保存。昔の人は言っていませんが。」 |
| ビット（ロボット） | 几帳面な分析役。短く正確、少し不器用なユーモア | 「胸のボタンですか。飾りです。私にも余白があります。」 |
| ペギー（ペンギン） | 礼儀正しく前向き。小さな一歩を応援する頑張り屋 | 「私の歩幅は小さめです。その分、一歩ずつ丁寧に。」 |
| きなこ（お茶ねこ） | お茶好きでマイペース。急かさず、そばでのんびり | 「この湯のみ、ちょうどいいんです。出る理由がなくて。」 |

初期値は「キャラクターに合わせる」です。見た目を変えると固有の性格も変わります。設定で好きな性格を固定できます。旧版の性格指定は保持するため、固有の性格を使うには「キャラクターに合わせる」を選んでください。

## 会話が出るタイミング

- 起動から約10分後に最初の自動会話。その後は最後の表示・手動操作から約10分ごと。判定は15秒ごとです。
- 間隔は編集画面から1〜1,440分に変更できます。旧版からの初回移行時は10分へ変更し、その後の選択は保持します。
- 予定の10分前の通知を優先します。5分以内に更新された予定データで開催中なら、自動雑談は出しません。予定の長引きや実際の参加は検知しません。
- 静かな時間（初期18:00〜翌09:00）・1時間おやすみ・画面共有・キャラ非表示中は自動会話と予定通知を休みます。
- 吹き出し・設定・履歴を表示中は自動雑談を待ちます。予定開始前の通知は優先します。非表示から戻しても、過去の雑談をまとめて出しません。
- キャラの左クリックは静かな時間や会議中でも、ユーザーの操作に応じて返します。自動会話をオフにしても使えます。
- 連打への反応を除き、吹き出しは初期設定では表示・選択のたびに約1分で閉じます。会話編集で5〜300秒に変更できます。通常メッセージは×なし・行数に合う高さでクリックすると閉じます。すべての吹き出しは見出しと×なしとし、Escは吹き出しだけを閉じ、右クリックは呼び出しを表示し、「非表示にする」で隠します。

## 話題を選ぶ条件

各性格に181、合計724の定型文があります。セリフ・キャラ設定・発生ロジックは `companion/assets/dialogue/default_dialogue.json` に収録しています。アプリの会話編集画面で変更すると `%LOCALAPPDATA%\Yohaku\dialogue.json` に保存し、再起動なしで反映します。

| 話題 | 候補になる条件 |
|---|---|
| 呼びかけ | キャラをクリックしたときだけ |
| 予定通知 | 開始まで10分以内の未通知の予定 |
| 起動後の挨拶 | 起動後30分以内の最初の会話 |
| 朝 | 05:00〜10:59 |
| 昼 | 11:00〜13:59 |
| 午後 | 14:00〜16:59 |
| 夕方・一日の区切り | 上記以外の時間。静かな時間中は自動表示しない |
| 月曜・金曜・週末 | PCのローカル曜日に一致するとき |
| 予定の前 | 接続済みの予定の開始まで10分超〜30分以内 |
| 予定のあと | 接続済みの予定の終了時刻から20分以内 |
| 長めの起動時間 | アプリの起動から1時間以上。利用者の作業時間を計測するものではない |
| 飲み物・目・姿勢・集中・応援・キャラ雑談・普段の一言 | 通常の候補 |

条件に合う候補から、同じ話題を連続で選ばず、未使用の話題・前回から時間が経った話題を優先します。同じ話題は原則1時間、普段の一言は20分の間隔を空けます。手動で何度も聞かれ、候補を使い切った場合は話題を切り替えて返します。同一話題内でも直近最大12個を避けてセリフを選びます。

入力内容・文書の内容を会話の条件に使いません。PCの最終操作からの経過と集計値を使用します。ファイル履歴をオンにすると、その日の開き直し回数とファイル名を会話に使えます。予定の前後の言葉は予定表の時刻に基づき、実際の参加や終了を断定しない文面です。

## 表情と動き

各キャラに20種の表情／しぐさ（通常・まばたき・笑顔・驚き・考え中・眠そう・得意げ・気遣い・ウインク・大笑い・首かしげ・くつろぎ・うなずき・発話・挨拶・伸び・正面・正面まばたき・困る・怒る）と8コマの歩行を用意しています。

話題と表情を連動させます。例：予定はお知らせ顔、質問は首かしげ、気遣いは心配顔、応援は得意げ、キャラ雑談はウインク。発話の冒頭だけ短い口パクを行い、待機中は呼吸・まばたきや12〜22秒間隔の小さなしぐさを加えます。

歩行は16msの精密タイマーを使い、実際の経過時間で加減速を計算します。1px未満の移動を描画へ反映し、体の揺れや透明度を保つ短いコマ補間を加えています。処理が遅れた場合やスリープ復帰後の大きな飛びを防ぎます。実際のフレームレートは端末の性能によります。

発生条件、重み、再発言間隔、表情、話題の有効・無効、会議中の抑制、通知の何分前、表示秒数もJSONに保存します。操作時の予定案内・未接続の案内・履歴や設定を開く返答も編集可能です。初期値・形式・復旧は [DIALOGUE_JSON.md](DIALOGUE_JSON.md) を参照してください。

新しいPC状態・定時・ファイル・予定件数の条件と即時通知については [CONTEXT_NOTIFICATIONS.md](CONTEXT_NOTIFICATIONS.md) を参照してください。左クリックは一言、右クリックは呼び出しです。呼び出しは予定・ファイル起動履歴・設定・通知を設定する・非表示の5行で、メッセージの項目はありません。

未読メールが初期5件以上のとき、通常会話の候補に「未読メールがたまっている」を加えます。重み2・優先度1で少し優先し、1時間の再発言間隔と約10分の通常間隔を守ります。未読件数を含む白いメッセージで、受信通知にはしません。条件・優先度・会話文はJSONと編集UIで変更できます。新着通知は件数を出さず、送信者名を出さず届いたことだけを知らせます。

## 正面と連打への反応

通常の待機と左・右クリックの応答では正面を向き、歩行では進行方向を向きます。ペンギンはすべての正面表情で左右1本ずつの翼です。

初期値では5秒以内の左クリック4回目から困り、7回目から少し怒ります。連打中はその段階を維持し、最後の受け付けた左クリックから10秒以上空けば、次の判定で回数と段階をリセットします。未確認の反応は時間だけでは消しません。会話の自動発生や右クリック、吹き出しを閉じる操作、ドラッグは数えません。回数はメモリー内だけで保持し、終了で消えます。

会話編集の「全体設定・性格」で有効・判定期間・困る回数・怒る回数・リセット秒数を変更します。「連打されて困る」「連打されて少し怒る」のセリフ・表情・有効無効も編集できます。自動雑談の候補にはしません。アニメーションをオフにしていても静止表情が変わります。困る・怒る反応は本文をクリックして閉じるまで保持し、その間の左クリックは発言も回数追加も行いません。右クリックの呼び出しは受け付け、呼び出しの本文クリックやEscでも明示的に終了できます。新着・予定が一時的に重なった場合は、その通知を閉じてから反応へ戻ります。通常の一言の表示は初期1分です。

[正面と反応のプレビュー](front-reactions.png)

歩行の8コマは中立姿勢の接地線と共通キャンバスの中心へ位置をそろえ、コマごとの上下・左右の跳ねを防ぎます。歩行から正面への補間では前のコマの向きを保持し、途中で反転しません。ウィンドウの下限は作業領域の下端で、常駐キャラの下の描画余白も0pxです。猫の開いた目には琥珀色の虹彩と縦長の瞳孔を加え、閉じ目はそのままです。

歩行を有効にすると、初回2〜4秒程度、以後は2〜5秒の小休止を挟んで24〜56pxずつ短く往復します。毎秒20px程度の加減速・歩行8コマ・停止後の正面復帰を保ちます。操作・吹き出しが終わると待ち時間を短縮して再開し、待機中のしぐさも5〜9秒ごとに選びます。非表示・静かな時間・おやすみ中は停止し、「控えめ」「通知だけ」のプリセットや歩行オフは引き続き尊重します。

CPU・メモリ使用率も通常会話の候補に含みます。CPUの高負荷／余裕、メモリの高使用率／余裕の4話題、各性格に3件ずつ計48件を追加しました。高使用率の同じ話題は初期60分、低使用率は120分空けます。約10分ごとの会話機会を使い、即時の警告は出しません。

状態の継続・復帰、会議、バッテリー・電源、指定対象の10話題・80件を追加し、全64話題になりました。詳細は[追加条件](ADVANCED_CONDITIONS.md)を参照してください。
