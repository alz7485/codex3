- プレビューをモデル／レイアウト名のタブに分離。表示倍率と移動位置を空間ごとに保持。

- DWG／DXF読込に「レイアウトも含める」を追加。紙上図形を空間別に登録。
- 対応するビューポートの矩形枠、平面ビュー中心・尺度・ロック状態を読込。傾いた視線・非矩形クリップ等は注意事項を表示。

空間・レイアウト・ビューポート操作とシステム変数の一括設定も含みます。プレビューはビューポート内部の投影を再現しません。プロッタ等の印刷設定の完全な取り込みも対象外です。詳細は同梱docs/LAYOUT_COMMANDS.mdを参照してください。
