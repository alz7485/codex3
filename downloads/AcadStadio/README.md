# AcadStadio

最新: **v1.58.0-beta83 — 点参照をコンパクトな別窓へ**

[更新ZIP](AcadStadio_v1.58.0_PointWindowTrial83.zip) / [SHA256](AcadStadio_v1.58.0_PointWindowTrial83.zip.sha256)

点参照をプレビュー側の下寄りに開くコンパクトな別窓へまとめました。参照元と点を1行で選び、XY/X/Y・移動量・変更前後を確認できます。交点や接点などは「詳細」から指定します。元のプレビューで図形と点を選び、ボタン・Enter・テンキーEnter・右クリックで確定すると別窓が閉じ、次の点のX入力欄へ戻ります。キャンセル・Esc・×は未確定の選択を取り消します。プレビューの表示領域・拡大率を維持し、別窓はドラッグ移動できます。紐づけ支援とonedir EXEビルド手順も同梱しています。

コア389件・GUI363件、計752件のテスト通過。Windows実機のAutoCAD実行・EXE動作は未確認です。使い方は同梱 docs/POINT_REFERENCE_WINDOW.md を参照してください。
