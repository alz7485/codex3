# AcadStadio 1.37.1 — 試用版48

**[試用版48 ZIPをダウンロード](https://github.com/alz7485/codex3/raw/refs/heads/main/downloads/AcadStadio/AcadStadio_v1.37.1_WorkbenchStyleTrial48.zip)** ／ [SHA256](AcadStadio_v1.37.1_WorkbenchStyleTrial48.zip.sha256)

Excel / CSVの行と作図コマンドから、AutoCAD用SCRを生成するローカルアプリです。プロジェクト → ブロック → コマンドの順に管理します。

## 見た目の調整

- 白い点カード、淡い枠線、入力中の点の青い強調、参照元の紫の帯を採用。
- 見出し横の参照ボタンを自然な小ささにし、入力方式を含む上部をコンパクトに整理。
- コマンドの点参照では、参照点とX/Y/XYを青い選択ボタンで切り替える。
- 適用前後の座標をカードで表示し、X/Yのずらし量を横並びに配置。
- 点選択の左フォームも必要時だけスクロール。確定操作と右のプレビューは固定。
- 入力欄/選択欄の背景と枠線、主操作/副操作の配色を調整。

## コマンドを追加・編集

1. ブロック編集の分類アイコンからコマンドを追加します。
2. コマンドと入力方式を上部で指定。コマンド選択時に分類/検索を利用できます。
3. 点のX/Yを横並びで入力し、見出し横の表・コマンド・変数ボタンで参照を選択します。
4. 右のプレビューと入力欄下の計算結果で、確認行の形を確認します。計算結果は参照や式のある欄だけ表示します。
5. 「追加して続ける」で続けて登録し、「追加して閉じる」で終了します。編集では「変更を保存」です。

コマンドの点参照は左側を選択画面へ切り替え、同じプレビューで図形/点をクリックします。X/Y/XYを選び、ずらし量は方向別に指定できます。既存の参照を開くと設定を復元します。「この点を使用」で適用し、「キャンセル」で入力へ戻ります。

表と変数はそれぞれの選択画面で入力先X/Yを指定します。表はセルや列を直接選び、選択箇所を色で表示します。

Ctrl+Z/Ctrl+Yで編集中の変更を戻す/やり直すことができます。XYの上書きは1回で両欄を戻します。円・円弧は方式ごとに入力値を保持し、切り替えて戻すと復元します。倍率と移動位置は入力変更や参照選択で維持し、「全体を表示」で合わせ直します。

「追加して続ける」で確定したコマンドは後続の参照候補に入ります。その後の入力をキャンセルしても、確定済みの分は残ります。ブロック編集全体を取り消した場合は、そのブロックの変更を破棄します。

## 入力方式と参照

- 線分/ポリラインは＋で連続点を追加。始点・中間点・終点を管理します。
- 円は半径/直径、円弧は中心・半径・角度／始点・通過点・終点／始点・中心・終点を切り替えます。
- 表の列/セル・変数・先行コマンド/ブロックの点を参照できます。
- 表参照は青、コマンドの点参照は紫、変数/設定値参照は緑で、入力欄全体を色分けします。
- ガイドは最上位の補助図形で、薄いプレビューと点参照に使用し、SCRには作図しません。
- レイヤー・線種・色・線種尺度・スタイルの空欄は現在の設定を引き継ぎます。詳細設定は常時表示です。

参照はSCR生成時に座標を計算する機能です。CADオブジェクト選択に使う場合、その実体が先に作図されている必要があります。

## 起動

Python 3.11以降（tkinterを含む）で展開フォルダから実行します。

```powershell
py -3 -m pip install -r requirements.txt
py -3 src/main.py
```

## Windows onedir EXE化

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt pyinstaller
.\.venv\Scripts\python.exe -m PyInstaller --clean --noconfirm AcadStadio.spec
```

出力は `dist/AcadStadio/AcadStadio.exe`。配布時はフォルダ全体を渡してください。ZIPはソース版で、EXE本体は含みません。
