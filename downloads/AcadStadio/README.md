# AcadStadio Trial72

[最新版ソースZIP](https://github.com/alz7485/codex3/raw/refs/heads/main/downloads/AcadStadio/AcadStadio_v1.52.0_CoordinateBuilderTrial72.zip)

座標カードの「計算」から、開始位置・間隔や中心・半径／直径などを入れてX/Yの式を自動作成できます。指定位置からの移動、距離と角度、繰り返し内の横・縦・円周配置に対応。表・変数を選択でき、配置図と座標一覧で確認できます。

子コマンドの編集は繰り返し1回目を表示し、入力補助では回数分の位置を試算します。設定値の再編集、X/Y一括反映とUndoに対応。既存の式・保存形式・通常のREPEAT出力は維持します。使い方は docs/COORDINATE_FORMULAS.md、操作例は examples/coordinate_placement_project.json に同梱。

コア355件・実Tk GUI332件合格。面取り・角丸め、前点ボタン、フランジと継手の部分サンプルも含みます。Windows EXE・AutoCAD実機は未検証。onedir EXE化コマンド同梱。ユーザープロジェクトのDataは含みません。
