# AcadStadio 1.21.1 — 上部をコンパクトに・試用版11

**[試用版11 ZIPをダウンロード](https://github.com/alz7485/codex3/raw/refs/heads/main/downloads/AcadStadio/AcadStadio_v1.21.1_CompactHeaderTrial11.zip)** ／ [SHA256](AcadStadio_v1.21.1_CompactHeaderTrial11.zip.sha256)
アプリ内の大きなタイトル・ロゴ・キャッチコピーを削除し、プロジェクト名と操作ボタンを上部1段に集約しました。確認した画面ではプレビューの高さが106px増えています。

作図設定を「行番号で1行」「チェックリストで複数行」の2つに整理しました。ブロック編集には、クリックしたコマンドまでを累積表示するモードを追加しました。

- 行番号をスピンボタンで変更し、指定した行のタイトルを隣に表示。
- タイトルは入力表一覧の1番目の表（入力表1）の左端のデータ列から取得。アプリが付ける行番号列は含めません。
- 「選択行…」で行番号とタイトルだけのチェックリストを別窓表示。「すべてチェック」「すべて外す」「適用」「キャンセル」に対応。
- 作図対象はチェックリストで確定した行。入力表の編集選択を変えても作図対象は変わりません。
- メイン画面と小さい画面の作図設定ダイアログで同じ配置を使用。
- ブロック編集の「選択したコマンドまで表示」をONにすると、先頭〜クリックしたコマンドを累積表示。対象のコマンド行を色で示し、「ここまで3/6」のように進行を表示。
- 後続コマンドが未完成でも、選択した段階まで確認できます。モードは作業状態として記憶し、プロジェクトの作図コマンドは変更しません。

画像の構成に合わせて、左に断面図（A-A）・右に平面図を並べた段付きフランジを標準サンプルにしました。中心穴と取付穴は、いずれもねじのない通し穴です。

- 平面図に外周・段の外周・中心穴・等配の取付穴・PCD・中心線を表示。
- 断面図に板厚と段差を表示。上下の取付穴と中心穴を通る切断面です。
- 断面の端面・外周線は穴の位置でも途切れさせず、全体を連続して表示。
- ボルト穴の上下2辺を板厚全体、中央穴の上下2辺を段を含む全厚にわたって表示。
- ハッチングを削除。ブロックは平面図・断面図・寸法図名の3つに整理。
- 外径・段の外径・中心穴径・板厚・全厚（板厚＋段の高さ）の寸法を表示。
- 入力表の寸法変更に両図が連動。JSON・CSV・Excel・生成SCRも更新。
- 初期表示は1行目。寸法違いの3行を同梱し、追加のLINファイルなしで作図できます。

Trial6で整理した操作画面も継続しています。

- メイン画面をプレビュー専用に変更。プレビュー／SCRのタブは廃止。
- 入力表選択の右側と、その下の作図条件表示を削除してプレビューを上へ拡張。
- 生成SCRは右上「SCRを表示」から別ウィンドウで表示。コピー・再生成・書き出しができます。
- 各表に縦横の罫線を表示。スクロールや列幅変更にも追従します。
- DWG設定読込の絞り込み欄を削除し、チェック表へ統一。
- DWGを読込画面へドラッグ＆ドロップ可能（Windows）。1ファイルを受け付け、そのまま読み取りを開始。
- LINファイル指定欄を廃止。線種はCAD側に存在する同名の線種を使用。



画面キャプチャはチャット内で提示し、配布ZIPには含めていません。

## 起動

Python 3.11以降（tkinterを含む）が必要です。ZIPをすべて展開し、フォルダで実行します。

```powershell
py -3 -m pip install -r requirements.txt
py -3 src/main.py
```

`AcadStadio.pyw` からも起動できます。DWGの読取はWindows版AutoCADを起動して利用します。

## サンプルの寸法

|列|意味|
|---|---|
|TYPE|部品の識別名|
|X / Y|平面図の中心位置|
|OD|外径|
|ID|中心穴径|
|PCD|ボルト穴の中心円直径|
|R|ボルト穴の半径（穴径は2×R）|
|N|ボルト穴数（同梱例は4・6・8）|
|T|本体の板厚|
|HUB_D|段の外径|
|H|段の高さ（全厚はT＋H）|

「入力表」で編集し、「作図設定」の対象行で切り替えます。初期表示は行番号1、タイトルFL-100です。複数部品は「選択行…」でチェックし、全3部品なら「すべてチェック」→「チェックした行を適用」と操作します。
図の間隔は共通設定 `VIEW_GAP` で調整できます。
サンプルは中心穴と上下の取付穴を通る、偶数穴の段付きフランジです。寸法は `0 < ID < HUB_D < PCD - 2×R`、`PCD + 2×R < OD`、`R > 0`、`T > 0`、`H > 0` を満たす値にします。Nは正の偶数です。形状が成立しない値の自動補正はありません。
輪郭と破線は通常の線分として生成し、CADの線種定義を追加しません。
CAD初期設定はサンプルでONです。既存図面の同名レイヤーを使う場合はOFFにできます。

## 作図

1. 「入力表」でExcel / CSVを読み込み、使用する入力表を選びます。
2. 「ブロック追加」でコマンドを直接追加します。入力値は `@OD / 2`、共通設定は `settings.TEXT_HEIGHT`、変数は `変数.参照行` で参照できます。
3. 「表・変数」から表の列・セルを選んで参照式を入力できます。複数表・固定行・変数での行指定に対応。
4. 左下「作図設定」で、行番号をスピンボタンで1つ指定するか、「選択行…」のチェックリストで複数行を選びます。フォルダ利用時や小さい画面では「作図設定…」から同じ操作ができます。
5. プレビューを確認し、右上「SCRを表示」または「SCRを書き出す」を使います。
6. プロジェクトはCtrl+SでJSON保存します。

## 行タイトルとチェックリスト

行番号は1から数えます。カンマ区切りや範囲指定は使用しません。タイトルが空なら「タイトル未入力」、入力表1に同じ行がない場合は「入力表1に該当行なし」と表示します。長いタイトルは省略表示し、マウスを置くと内容を確認できます。

チェックリストの行数とタイトルは入力表1のものです。別の入力表を作図に使用していて、その表に存在しない行はチェックできません。チェックをすべて外して適用すると作図対象は0行となり、プレビュー・SCRを空にします。

チェックリストで適用した内容と行番号は入力表ごとにJSON保存され、元に戻す／やり直すにも対応します。

## ブロックの進行を確認

ブロックを開き、プレビュー上部の「選択したコマンドまで表示」にチェックします。コマンドをクリックすると先頭からそのコマンドまでを表示します。前の行に戻ればその段階まで戻ります。IF・REPEATは、そのコマンド内で実行される図形をまとめて表示します。

一覧の色はプレビュー対象を示します。編集・削除の対象は実際にクリックして選択したコマンドです。チェックを外すと選択したコマンド単独の表示へ戻ります。

## DWGから設定を取得

「CAD初期設定…」→「DWGから読み込み…」を開きます。DWGを画面へドロップするか、「参照…」で選択して読み取ります。
AutoCADを起動しておいてください。読取後に登録する項目へチェックし、「チェックした項目を登録」→「設定を確定」で反映します。

線種は名前の登録だけです。形状定義は複製せず、使用するCAD図面に同名の線種があることが必要です。追加のLINファイルは指定しません。
詳細は [CAD初期設定](ZIP内 docs/CAD_INITIALIZATION.md) と [複数表・行指定](ZIP内 docs/TABLE_ROW_REFERENCES.md) を参照してください。

## onedirでEXE化

```powershell

.\.venv\Scripts\python.exe -m pip install -r requirements.txt pyinstaller
.\.venv\Scripts\python.exe -m PyInstaller --clean --noconfirm AcadStadio.spec
```
