# Trial61 CSVのない月度分を非表示

- メインの表示切替の横に「CSVが無い月度分は非表示」を追加。起動時はチェックONです。
- 対象期間のうちCSVに記録がない年月の「CSV記録なし」による要確認を一覧から除外します。例えば2026年10月度で10月CSVしかない場合、9月16〜30日の該当する要確認を隠します。前月CSVだけなら当月分を隠します。
- ファイル数や名前ではなく、読み込んだCSVの日付で判定します。1ファイルに両方の年月があれば除外しません。年末年始にも対応します。
- 月内の一部社員・一部日だけのCSV欠落は表示します。入力異常・重複・未登録IDなど別の原因の要確認も残します。
- CSVの読込失敗や日付・識別情報の不正で月の判定ができない場合、CSVが空、対象年月のデータが全くない場合は隠しません。元Excelに入力異常があるCSV欠落行も残します。
- チェックを外すと再読込せずに全件へ戻ります。検索・不一致のみ／すべての切替と併用でき、印刷も表示中の一覧を対象にします。
- 下部の件数欄に「CSVなし非表示」の件数と年月を表示。全数・各状態の集計・読み込み診断は元の結果を保持し、表示を隠すだけで全数一致とは判断しません。
- 設定の対象年月を変更しても、読込済み結果の年月度で表示を切り替えます。中止・読込失敗時は前回の表示を保持します。
- 前版のコンパクトな横幅、社員情報の事前登録、CSV自動読込、メール作成機能を維持。図解18ページも更新しました。
