起動時の月度と、社員ID管理の初期表示を調整しました。

- 起動時のPCの日付の年・月を、そのまま対象月度に設定します。10月中の起動は10月度（9/16～10/15）です。10月16日以降の勤怠照合作業に対応します。1～15日も同じ月度を選びます。
- 前回保存した月度より起動日を優先し、起動後の手動変更は保持します。
- 社員ID管理は未紐づけの社員を初期表示し、未紐づけが0人なら全員を表示します。
- 月度日数・全数計算式・一致／不一致／判定要確認／未照合の表示を継承。項目追加・ON/OFF・JSON拡張設定の保持に対応します。

![2026年10月16日の起動を想定した画面例：10月度を自動指定](Trial43_Startup_Month.png)

全数は「ON照合項目数 × 読み込み済みXLSX社員数 × 月度日数」です。欠落や読み込み失敗がある場合は全数一致とは表示しません。未読込社員の人数は全数に含められないため、読み込み診断も確認してください。

画像付き操作マニュアル・設定・監査報告を同梱したソース版です。ZIP展開後、CODEX_START_HERE.txt と AttendSync/README.md を参照してください。Python環境と依存ライブラリが必要です。ビルド済みEXEは含みません。
