# 勤怠チェッカー Trial54 — 不一致メール作成・自動送信設定

メイン画面「表示リストを印刷」の左に封筒アイコン付き「メールを作成」を追加。表示中の不一致だけを社員ごとに集計し、その社員の紐付け済みメールへ不一致内容を差し込む。要確認と一致はメールに含めない。宛先未登録・保存済みIDとの不整合は対象から除外し理由を表示。

設定に「メール」タブを追加。必ず入れるTo/CC、差出人名（本文用）、宛名の敬称、件名・本文・署名を編集可能。差し込みは社員名/社員ID/スタッフID/対象年月/不一致件数/不一致内容など。メール設定は保存後すぐ反映し、年月度は読み込み済み結果の期間を使う。

「メール作成時に自動送信する」を追加（初期OFF）。OFFはMicrosoft 365の下書きへ保存、ONはメール作成画面でチェックした社員のメールを送信。読み込み・照合だけで送信する動作はない。Microsoft 365/Exchange Onlineの新しいOutlookメールボックスへMicrosoft Graphで処理する。

接続には会社のMicrosoftアプリ登録、デスクトップのlocalhostリダイレクト、委任権限、アプリID/テナントID/送信アカウント設定が必要。ブラウザ認証でアカウントを照合。Windowsの認証キャッシュはDPAPIで暗号化。クライアントシークレットを使わない。

送信履歴・排他ロックで同内容の二重処理を防止。送信中の通信エラーは結果不明として自動再送を止める。処理の途中失敗では残りを停止し、保存/送信済みと未処理を区別。送信受付202は配達完了を意味しない。

UI図解19ページ、Microsoft連携ガイド、必要ファイル版・完全版ZIPを同梱。msalを依存に追加。Windows EXEと会社テナントへの実接続/実送信は未検証。
