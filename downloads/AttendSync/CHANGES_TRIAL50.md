# AttendSync Trial50 — 監査6件の修正

1. **M-01**: XLSX側とCSV側で正規化氏名が一意の場合だけ自動ID対応。同姓同名は全員手動確認へ。既存手動対応を保持。
2. **D1**: キャッシュ保存失敗時はロールバックを試み、警告を記録して解析済みデータを保持。入力ファイルの読み込み失敗とは区別。
3. **D2**: キャッシュのrecords/info/必須レコード属性/values/invalid_fields/warningsの型を検証。構造不正は元ファイルから再解析。
4. **U1**: 未紐付け行も含め全社員番号を独立した集合で重複検査。順序に依存せず保存を拒否。
5. **S-01**: 設定保存成功後、テーマを画面・ボタン・アイコン・結果表に即時適用。保存失敗時は設定と表示を保持。
6. **U2**: 印刷/プレビューダイアログをfinallyで解放。キャンセル・印刷エラーでも親ウィンドウへ蓄積しない。

過去の自動ID対応は所属の正解を推定できないため自動削除しない。同姓同名がある場合は既存対応表を社員番号・スタッフIDで確認し、社員ID管理から必要な訂正を行う。

Trial49の18章/59ページマニュアル、採用アイコン、onedir配布、項目追加・未知JSON保持を継承。ソース版ZIPでありWindows EXEは含まない。Windows実機・実Excel・実プリンターは未検証。

仕様確認扱いのExcelフル日付とSQLiteバイナリ破損の自動復旧は今回の確定6件と別で未変更。
