# Trial63 起動中のクラシックOutlookから設定を取得

「設定」→「メール」に「起動中のOutlookから取得」を追加しました。

1. WindowsでクラシックOutlookを開きます。
2. 取得ボタンを押します。メールアカウントが複数あれば、使うアカウントを選びます。
3. メールアドレスが「接続するアカウント」、表示名が「差出人名（本文用）」へ反映されます。「設定を保存」で確定します。

取得に失敗した場合・選択をキャンセルした場合は入力を保持します。表示名を取得できない場合も手入力した差出人名を保持します。Outlookの起動やプロファイルの切替、メール作成・送信は行いません。現在起動中のOutlookに接続してアカウント情報だけを読み取ります。

取得できるのはメールアドレスと表示名です。MicrosoftアプリID・テナントIDや必須To/CC、本文・署名は設定画面で指定します。下書き保存・送信は従来どおりMicrosoft Graph経由なので、Microsoftアプリ登録と初回サインインが必要です。

WindowsのクラシックOutlook専用です。起動中のOutlookを取得できない場合は、Outlookとツールが同じWindowsユーザー・権限で動いているか確認してください。必要なpywin32はrequirements-build.txtに加えてrequirements.txtにもWindows用依存として指定しました。
