# Trial57 社員情報CSVの列配置

紐付け用CSVの初期値を実際の列配置に合わせました。

| 列 | 取り込む項目 |
| --- | --- |
| A | スタッフID |
| B | 社員ID（CSVの見出し：派遣元スタッフコード） |
| C | 氏名 |
| J | メールアドレス |

B列の見出しが「派遣元スタッフコード」でも、アプリでは社員IDとして扱います。列記号で読み込むため、見出し名そのものに依存しません。見出しが1行の標準開始行は2です。画面の社員ID列にも見出し名を併記しました。

保存済みの列指定は保持します。以前のA/B/C/Dなどが表示される場合は、「社員情報」→「社員情報を読み込む」→「紐付け用CSV」で社員ID=B、スタッフID=A、名前=C、メール=Jへ変更し、「照合して確認」→「一覧に反映」→「紐付けを保存」で更新してください。

勤怠用CSVの列設定・メールを変更しない取込、二つのIDによる紐付け、未紐付け候補、手動入力、メール作成時の送信切替はTrial56を継承します。図解マニュアルの社員情報CSV画面と説明も更新しました。

派遣元の勤怠XLSXが将来CSVに変わる可能性を引き継ぎに記録。派遣元CSVの勤怠読込自体は現時点で未実装です。
