# Trial56 社員情報の統合とメール作成時の送信切替

- 「社員ID」「メール管理」を「社員情報」の1画面へ統合。社員ID・氏名・スタッフID・メールを同じ行で確認し、IDとメールをまとめて保存します。初期表示は全員で、ID未紐付け／メール未紐付けへ絞り込めます。
- 「社員情報を読み込む」からCSVの用途と列を指定します。見出し名の確定を待たず、列記号で使用できます。
  - 紐付け用CSV：社員ID・スタッフID・名前・メール。両IDの組で新しいID対応とメールを取り込みます。既存IDの競合・多重割当は自動上書きせず、有効な未紐付けメールを候補へ保持します。
  - 勤怠用CSV：勤怠照合に加えてIDだけを紐付けます。メールは変更しません。社員ID列がなければ空欄にし、スタッフID候補を一覧で選択します。名前だけでは自動確定しません。日別の同一情報はまとめます。
- 紐付け用として保存したCSVパスを勤怠の一括読込から除外します。用途の記録はファイルパス単位です。移動・改名後は読込画面で再指定してください。勤怠照合には、従来どおりメイン画面で指定したフォルダのCSVを使います。
- CSVの「一覧に反映」ではファイルへ保存しません。「紐付けを保存」でID・メール・用途・列設定を確定し、キャンセルは取込と編集を破棄します。二つの保存ファイルは回復用記録で保護し、途中失敗・次回起動時に元の状態へ復元します。
- メール作成画面にも自動送信ON/OFFを追加。OFFはOutlookの下書き、ONは送信。今回の処理だけに適用し、設定画面の初期値は変えません。処理中は切替不可です。
- 敬称「殿」、派遣元／派遣先のみの本文表記、全メールの必須To/CCを継承。保存済み文面も維持します。
- 図解マニュアルは統合画面・2種類のCSV・送信切替を反映した19ページです。

ソース版です。Microsoft 365アプリ登録・接続設定が必要です。実テナント送信とWindows EXEは未検証です。
