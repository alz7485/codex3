# Trial58 社員情報CSVのドラッグ読込と画面整理

- 「社員情報」と「社員情報を読み込む」の画面へCSVを1ファイルだけドロップして読み込めます。入力欄・一覧の上でも受け付けます。社員情報画面では読込画面が開き、確認一覧まで自動表示します。
- 読込画面では、選択中のCSV用途・列指定・開始行・文字コードを使います。紐付け用の初期列はスタッフID=A、社員ID（派遣元スタッフコード）=B、氏名=C、メール=J。保存済みの列指定は保持します。
- CSV行番号の表示を削除。一覧はスタッフID・社員ID・氏名・メールアドレス・照合結果の5列です。元CSVの行位置は内部で保持します。
- 確認一覧をダブルクリックすると、元CSVをWindows版Excelで開き、クリックした項目の対応するセルへ移動します。照合結果欄や、元CSVに列のない項目はスタッフIDのセルを選びます。新たに開くブックは読み取り専用です。既に開いているブックは再利用します。
- 元CSVが読込後に更新されていたら、セル移動を止めて再読込を案内します。列や用途を変更した場合も、古い確認一覧をクリアします。
- CSVファイル、読み込み設定、確認一覧、操作ボタンの順に配置。列入力を均等な幅で揃え、メール欄を広げ、一覧の行高も調整しました。
- 複数ファイル・フォルダ・CSV以外・Webリンクのドロップは受け付けません。ドロップのみで保存やメール送信は行いません。「一覧に反映」後、社員情報の「紐付けを保存」で確定します。キャンセルは仮の取込を破棄します。
- 図解マニュアルも更新。派遣元の勤怠XLSXが将来CSVへ変わる前提は引き継ぎに保持しています（派遣元CSVの勤怠読込は未実装）。

CSVのセル移動にはWindows版Microsoft Excelとpywin32が必要です。Windows EXEは同梱せず、ソース版として配布します。
