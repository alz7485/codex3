# Trial64 検証結果

全51テストスクリプトが成功しました。前版の50本（メール実行画面の期待動作をCOMへ更新）に、新規17テストを追加しました。

- 指定アカウントの下書きフォルダ・SendUsingAccountの固定、To/CC、件名・本文、下書きのみと保存→送信要求の順序。
- 空のアプリIDでも処理でき、未使用の旧ID値を変更しても同内容の重複を防ぐこと。
- 不明/重複送信元、送信元設定拒否、保存時の送信元変化、宛先解決失敗で送信しないこと。
- 下書き保存障害・曖昧な送信失敗・送信後の履歴書込障害、履歴の偽値/不正構造、OSロック、旧Graph履歴からの移行重複防止。
- 実Qtのメール作成画面からCOM処理用ワーカーを呼び、今回の自動送信設定を引き継ぐこと（処理関数は代替）。
- アカウント取得・選択・設定保存・未知JSON保持、勤怠CSV/XLSX・欠月表示・社員情報・集計・印刷など既存試験。
- ライト/ダークと通常/最小幅の4条件でメール設定に横スクロールが不要なこと、18ページの図解・画像とローカルリンク。
- 必要ファイル版と完全版で実行用ソースの内容が同じこと（必要版は未使用の旧Graph実装を除外）。ZIP CRCと全ファイルSHA256。

環境: Linux / Python3.12 / PySide6 / Qt offscreen。Outlookは合成COMオブジェクト、旧Graphは代替APIで試験しました。Windows実機でのOutlook接続・実送信・EXEビルドは未検証です。実メールは送信していません。
