# AttendSync Trial46 最終専門レビュー

## 最終判定

4人のレビュー専門エージェントが、照合・全数集計、設定・ID保存、UI・マニュアル、onedir配布・起動を独立監査した。再現した重大・中程度の指摘を修正し、担当者による独立再監査と親の統合テストを完了した。この環境で確認できるソース版の完成監査は完了。会社へ渡すWindows onedir EXEの実ビルド・実機受入は未実施。

## 発見と修正

| 問題 | 修正・再検証 |
| --- | --- |
| 正常30日がそろうと追加行の日・月が不正でも全数一致 | 不正な日・月・存在しない日付を追加要確認に計上。通常の有効な期間外行は従来どおり対象外 |
| 未計算の数式を本当の空欄として一致 | 日別列と設定された基本情報セルを検査。未計算・値キャッシュ欠落・数式エラーは要確認。計算済み数値・0・空文字は許可。A1と日別範囲後のA120でも検証 |
| 配布先と代替保存先が書込不可だと説明なしで起動終了 | 保存先・原因・対処を説明して終了コード1。原本保持。代替先のwrite/flushも起動時検査 |
| Enterで結果の詳細が開けない | Enterとダブルクリックの両方で詳細1回起動。F1とnativeキーボードcontextイベントも確認 |
| 閉じた設定・ID・詳細などの画面が親に残る | 各modalと右クリックメニューを終了後に解放。各3回の繰返し、保存成功／失敗でも残留なし |

数式はアプリで再計算しない。元Excelで再計算・保存して再読込する。基本情報の式が未計算のまま対象年月を推測して全数一致にすることも防ぐ。

## 変更と互換性

変更したPythonはengine.py、main.py、runtime_paths.py、cache_tags.py。新規Pythonは4回帰テスト。Pythonの削除なし。設定配置・枠線UI・onedirビルド・画像マニュアルの開き方を維持。未知JSON属性と項目追加の拡張性を維持する。

解析キャッシュの版を更新したため、更新後の初回読込は再解析する。既存の設定・社員IDは継続使用できる。旧userdataは更新前に必ずバックアップする。旧版でIDに表示用「—」が混入した場合はAUDIT_TRIAL44.mdを参照して元IDで登録し直す。

## 会社への配布

Windowsでrequirements-build.txtを導入してbuild_onedir.pyを実行し、生成されたdist\AttendSyncフォルダ全体を渡す。AttendSync.exe、_internal、Manual等を保持する。受け取り先へのPython導入は不要。ExcelジャンプにはMicrosoft Excelが必要。

このZIPは完全ソース・合成サンプル・画像マニュアル・独立レビュー・回帰テスト・ビルド手順。ビルド済みWindows EXEは含まない。
