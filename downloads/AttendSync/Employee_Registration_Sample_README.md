# 社員登録用サンプルCSV（4名）

AttendSync_Employee_Registration_Sample.csv を「社員情報」→「社員情報を読み込む」画面へドロップしてください。「一覧に反映」→「社員情報を登録」で確定します。

読込設定はスタッフID=A、社員ID=B、氏名=C、メール=J、開始行=2、文字コード=autoです。B列の見出しは「派遣元スタッフコード」です。D〜I列は空欄です。

UTF-8 BOM付きCSVです。すべて架空のサンプルで、メールは配信先として使用できない example.invalid を使用しています。

完全版ZIPのAttendSync/SampleDataに同梱した4名の勤怠サンプル（2026年10月度、社員ID10001〜10004／スタッフID S001〜S004）に対応します。田中 一郎は同姓同名の別社員2名です。ID2種類で区別します。

このCSVは社員登録画面で読み込み、勤怠CSVとして使用しないでください。登録後、SampleDataの勤怠を2026年10月度で照合すると一致357項目・不一致3項目・要確認0件が期待結果です。
