# Trial66 完成監査の確定11件を修正

- CA-01：キャッシュ署名にSHA256内容指紋を含め、同一サイズ・日時の差替えも再解析。解析前後の内容も確認します。
- CA-02：送信先To/CCの指紋を役割別に正規化・整列し、順序・大小文字・表示名の変更だけでは再作成しません。送信順は保持。旧COM/Graphの照合可能な履歴は新指紋へ引き継ぎます。
- CA-03：社員情報保存時に進行中workerを無効化・中止し、古い完了通知を拒否します。
- CA-04：社員情報更新後に結果・全数・指標・診断をまとめて未照合へ初期化します。
- CA-05：キャッシュの出典ファイル/行/シート・欠損/異常フラグを必須として検証。不完全な項目だけ元データを再解析します。
- CA-06：破損SQLiteを固有名で退避・再生成します。利用できなければ一時キャッシュで元データ解析を続行し、診断へ記録します。
- CA-07：社員編集の全割当を先に確認し、割当済みメール候補の大量複製を解消。連絡先はID対の索引で引きます。
- CA-08：社員CSV取込のスタッフ逆引きと氏名集合を前計算し、全件再走査を除去します。
- CA-09：メール設定の検証エラーを原因欄へフォーカスします。
- CA-10：比較形式の説明を文字列完全一致へ修正。HTML・18ページPDF・生成データを更新します。
- CA-11：入口案内・EXE化手順の版番号とPDFページ数を現行化します。

## 更新時の注意

userdataと旧メール処理履歴を事前にバックアップしてください。初回は新キャッシュ形式で再解析します。
旧履歴にハッシュしか残らず、旧宛先の順序・表記・表示名が不明な場合、過去の内容を完全復元して照合することはできません。旧条件で照合できた通知は新指紋へ引き継ぎます。旧条件不明の通知を再実行する前にOutlookの下書き・送信済みを確認してください。新形式の本文そのものは履歴へ保存せず内容指紋を保持します。

クラシックOutlook COM連携、アプリID不要、社員情報の事前登録、欠月非表示、メール作成のON/OFF、図解18ページを継承します。
本版はソース版です。Windows実機・Outlook実接続/配送・EXEビルドは未検証です。CSVをExcelで開いた際の式評価は、Excel/組織設定に依存する未検証リスクとして残ります。
