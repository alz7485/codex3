# Trial60 読込設定と画面横幅の整理

- 社員情報CSVの「社員ID列（派遣元スタッフコード）」を「社員ID」に変更。
- スタッフID・社員ID・氏名・メールの列指定、開始行、文字コードを1行へ統合。列入力は各54pxにし、長い入力欄を縮めました。
- 初期表示サイズを見直しました。CSV読込は1120×760→1000×700、社員情報は1150×700→1040×680、メインは1280×860→1180×800、メール作成は1160×740→1080×740です。
- CSV読込の最小幅940pxでも6項目が同じ行に収まり、ラベル・入力欄が欠けず重ならないことを確認しています。画面は引き続き手動で拡大できます。
- 社員情報を先に登録する流れ、未登録時の案内、登録後に勤怠を読み込む操作、CSV自動読込・保存済み列指定・ダブルクリックでの元CSV移動を継承します。
