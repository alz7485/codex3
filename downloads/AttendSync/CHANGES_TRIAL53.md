# 勤怠チェッカー Trial53 — メールCSV取込・手動紐付け

社員ID管理にメールアドレス列と「メールCSV取込」「メールを保存」を追加。

取込CSVは社員ID列・スタッフID列・名前列・メール列をA/B/C/Dなど列記号で指定。データ開始行と文字コードも指定可能。先頭0を維持。UTF-8 BOM/CP932自動判別。見出し名は使用しない。

保存済みの社員ID/スタッフIDが両方一致する行のみ自動紐付け。名前による自動対応はしない。ID空欄/重複/片側不一致、メール不正は理由付きで表示。

未紐付けの有効なメールは候補として保存。社員ID管理のプルダウンで選択、または直接入力し「メールを保存」。候補CSVのIDと異なる手動割当は保存前に確認。選択メールの重複・不正形式を拒否。ID未保存時は先に紐付け保存を案内。IDの組が変わると旧メールは表示しない。

自動メールと未紐付け候補、取込設定をuserdata/employee_contacts.jsonへ原子的保存。既存staff_mapping.jsonの形式は維持。メール保存とID保存は別操作。「メールを保存」または取込の「取込結果を保存」を押すと即時保存され、その後の管理画面キャンセルでは取り消さない。

図解を15ページに更新。実画面の社員ID管理・CSV取込を追加。メール送信機能は今回の追加範囲に含まれない。
