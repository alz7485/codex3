# 勤怠チェッカー Trial52 — 空欄表示の数式時刻

Excelの計算済み数式が数値0を返し、表示形式またはシートのゼロ非表示設定で空欄に見える場合、始業・終業と追加の時刻照合項目を空欄として読み込む。CSV側の実空欄と一致する。

- 数式の保存済み計算結果が0のセルだけを対象とする。
- h:mm;;、ゼロ用の空欄セクション、単純な数値条件によるゼロ非表示、sheetView.showZeros=falseに対応。
- 通常の表示される0:00、数式以外の値、実働・休憩等の時間0は保持。
- 数式が空文字を返すケースも従来どおり空欄。未計算・エラー数式は要確認を維持。
- XLSX/CSVキャッシュのパーサー版を更新し、旧キャッシュを次回読み込みで再解析する。設定と社員ID対応は保持。

実帳票の数式・表示形式は未確認。条件付き書式による文字色など、上記以外の非表示方法は判定対象外。Excelを起動して数式を再計算するものではない。
