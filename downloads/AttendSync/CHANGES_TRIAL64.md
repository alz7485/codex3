# Trial64 クラシックOutlookのCOM連携へ切替

前版はアカウント取得のみCOM、メール作成・送信はMicrosoft Graph経由でした。本版はメール作成・送信もCOM経由とし、MicrosoftアプリID・テナントID・アプリ登録・ブラウザでのサインインを不要にしました。

1. クラシックOutlookを起動します。
2. 「設定」→「メール」→「起動中のOutlookから取得」で送信元・表示名を入力します。複数アカウントは選択し「設定を保存」で確定します。
3. 勤怠照合後の「メールを作成」で社員ごとの宛先・CC・本文・対象を確認します。
4. 自動送信OFF（初期値）なら、選択したアカウントの下書きフォルダへ保存します。ONなら、下書き保存後に同じアカウントでOutlookへ送信を要求します。作成画面のON/OFF切替も維持します。

送信元をOutlookで一意に確認できない場合は中止し、既定の別アカウントへ切り替えて送信しません。宛先をOutlookで解決できない場合も送信しません。

処理履歴とOSロックで同内容の再作成・再送信を防止します。結果不明の送信は自動再試行せず、以降の社員は未処理として止めます。旧Graph版の送信元・アプリID等の履歴用設定が残っている場合は、その履歴も確認して重複を防ぎます。旧設定は移行のため保持しますが、COMの認証や送信には使用しません。

「送信要求済み」はOutlookへの要求完了で、配達完了ではありません。オフラインでは送信トレイに残る場合があります。Outlookの確認画面が出た場合は内容を確認してください。

設定画面のアプリID・テナントID欄を削除し、依存関係とビルドからmsalを外しました。18ページ図解とOutlook連携ガイドを更新しています。新しいOutlookは本版の対象外です。Windows向けのPythonソース版でEXEは同梱していません。
