# ACadPresetter RC39

Windows専用の修正版ソースです。AutoCAD 2025/2026 と Adobe PDFプリンターを使用する構成を対象にしています。元のRC38を基準に修正しています。EXEは含みません。

## Adobe PDFと「2つの値」の修正

ご申告は「2つの値を処理できずPDFが作られない」です。エラー全文を確認できていないため、個別の実機エラーの原因を断定していません。成功実績のあるTrial10gと比較すると、印刷原点の受け渡し形式に差がありました。

- `PlotOrigin` は、Trial10gと同じ `VARIANT(VT_ARRAY | VT_R8, (x, y))` で明示的にDouble配列を渡します。適用後だけでなく元の設定の復元でも同じ形式を使います。
- 窓の2点はTrial10gの通常タプルを先に試し、動的COMが拒否した場合は各点をDouble配列にして再試行します。
- `GetWindowToPlot` は通常の戻り値とBYREFの2つの出力引数に対応します。
- `GetCustomScale` は通常の2値、BYREF Doubleの2値、配列・VARIANTの2値を解釈します。BYREF呼び出しが戻り値を返すCOMラッパーにも対応します。
- 3つ以上の値、NaN、無限大、逆転した窓座標を適用せず、操作名・値・元のエラーを表示します。取得できない尺度を1:1に置き換えることはありません。

この受け渡し問題を模したCOMテストで、設定適用→Adobe PDFマクロ→PDF取り込み→元の尺度・原点・窓範囲の復元まで成功しています。実際のAutoCAD/Acrobatでの解消確認は未実施です。

## Adobe PDFの設定

1. Adobe PDFプリンター側で自動保存先を指定します。例: `C:\ACadPresetter\AdobeSpool`。最終保存先と分けた専用フォルダを推奨します。
2. Adobe側の「保存先を毎回確認」と「生成後にPDFを開く」をOFFにします。項目名はAcrobatの版によって異なります。
3. 本アプリの「設定」→「AutoCAD」→「Adobe PDF生成先」に同じフォルダを指定します。未指定で自動検出するという古い表示は削除しました。
4. 最終PDFの保存先・ファイル名は、PDF保存先／PDFファイル名プリセットで設定します。
5. 「PDF生成の待機時間」は標準120秒、30～600秒で変更できます。大きな図面では増やしてください。

出力にはTrial10gの `SendCommand / _.-PLOT` マクロを維持しています。Adobe PDFへPlotToFileを送る経路へは変更していません。

生成名は `元図面名.pdf`、`元図面名 (1).pdf`、`元図面名 (2).pdf` 等に対応し、今回新規作成または更新されたファイルだけを照合します。別図面の接頭辞一致や変化していない既存PDFは採用しません。同名候補が複数あれば停止します。

サイズと更新日時の安定に加え、PDF全ページと内容ストリームを読み取れることを確認します。生成元を一時的にAdobeがロックしている場合はコピーを再試行します。コピー中に変化したファイルや不正PDFは確定しません。

AutoCADのコマンド状態を読めない場合や、PDF生成の完了を確認できない場合は後続図面を停止します。既存PDFを処理前に削除しません。印刷前から存在したAdobe側PDFも自動削除しません。

## 全体の改善

- PDF生成待ち中にも画面の進捗・経過時間を更新します。中止は現在の処理の安全な区切りで反映します。
- 設定画面に生成先を開くボタンと待機時間を追加しました。
- コマンド状態、監視先、PDF検証結果を図面ごとの詳細ログに残します。
- 診断にはAdobe PDF生成先、フォルダ読み取り結果、待機時間を表示します。診断でPDFの実出力は行いません。
- PDF結合で元ファイルのWindowsハンドルを保持しない構成にし、入力検証・ページ数照合・一時ファイルの後片付けを追加しました。入力順、しおり、最初のPDFのタイトルを保持します。
- 空・破損・欠落入力による結合では既存出力を置き換えません。
- Layout由来のファイル名にも共通の文字処理を使い、拡張子付きのWindows予約名を補正します。
- READMEの古いDistiller経由の説明を現行のAdobe PDFマクロ経路に統一しました。
- PySide6／pypdfを今回検証したバージョンに固定しました。

## 更新と起動

既存の`data`フォルダは上書きしないでください。新しいプログラムを別フォルダに展開し、旧版を終了してから既存の`data`をコピーすると設定・プリセット・履歴を引き継げます。旧フォルダは確認が終わるまで残してください。

WindowsのPython 3.11または3.12（64bit）で、展開先から実行します。

```text
python -m pip install -r requirements.txt
python main.py
```

EXE版の作成は`BUILD_onedir.txt`を参照してください。修正版EXEを使うには再ビルドが必要です。

## エラーが続く場合に確認できる情報

- エラーダイアログの全文
- `data/last_run.json` の該当図面の `trace`
- ログ有効時は `data/logs/output_*.json`
- 診断レポートは `logs/diagnostic_*.txt`
- AutoCAD/Acrobatのバージョン、Adobe PDFの出力機器名、用紙名
