# RC41 検証記録

- 全体テスト: `QT_QPA_PLATFORM=offscreen python -X faulthandler -m pytest -q`
- 結果: **341 passed**、失敗・スキップなし。
- Pythonコンパイル: `python -m compileall -q app main.py tests` 成功。
- Python 3.12.14 / PySide6 6.8.3 / pypdf 6.20.0 / pytest 9.1.1。

## 旧版での再現

RC40の元コードでも個別に再現しました。

1. 正常に作成されたPDFでも、ファイル側の時計が印刷開始時刻より古いと検出結果がNone。
2. 日本語の見た目が同じでも、合成／分解Unicodeが違うと検出結果がNone。
3. 正常なPDF内容を更新しても、サイズとmtimeを保持すると検出結果がNone。

## RC41の追加テスト

- 開始時刻と1時間／1日／1年の差がある新規PDFの検出。
- 日時・サイズ・ファイル識別情報を固定しても、内容差分をSHA256で検出。
- 同じバイト列・サイズ・mtimeでファイルが置き換えられた場合の検出。
- 変更していない既存PDFは採用しないこと。
- NFC/NFD、NBSP、全角空白、余分な空白、全角括弧／全角1の照合。
- 正規化による新規候補の衝突を拒否すること。
- CAD名の全角英字を別のASCII名へ変換しないこと。
- 内容ハッシュを検出対象だけで取得し、通常の診断列挙ではハッシュを取得しないこと。
- 印刷前ファイルが読み取れず差分を確認できない場合は採用しないこと。
- 名前不一致時にフォルダ内の実ファイル名をログへ出すこと。

RC40の「全角スペースを無条件に不一致とする」既存テストは、今回の仕様に合わせています。空白なし・(2)等を誤採用しないチェックは維持しています。

検証環境はLinuxです。Windowsレジストリ・AutoCAD COMはテスト用の差し替えを使っています。実AutoCAD/Adobe PDF、Windows EXE、UNC実共有の動作は未検証です。
